🌊 Float - Java

Le float permet de stocker des nombres décimaux. Il utilise moins de mémoire qu'un double, mais possède une précision plus faible.

Un float nécessite généralement le suffixe f après un nombre décimal.

Sans ce suffixe, Java considère la valeur comme un double.

📌 Déclaration


float number;

float number = 10.5f;

Le f indique que la valeur est un nombre de type float.

📌 Calculs


number + 5f;

number - 5f;

number * 2f;

number / 2f;

Permet d'effectuer des opérations mathématiques avec des nombres décimaux. 


float result = number + 5f;

📌 Modulo (%)


number % 2f;

Retourne le reste d'une division. 


7.5f % 2f

Résultat : 


1.5

📌 Affectation simplifiée


number += 2f;

number -= 2f;

number *= 2f;

number /= 2f;

number %= 2f;

Permet de modifier une variable plus rapidement. 


number += 2f;

Équivaut à :


number = number + 2f;

📌 Comparaisons


number == 10.5f

number != 10.5f

number > 5f

number < 5f

number >= 5f

number <= 5f

Les comparaisons renvoient toujours : 


true

false

📌 Convertir une String en float


float value = Float.parseFloat("12.5");

Transforme une String en valeur float.

📌 Convertir un float en String


String text = String.valueOf(number);

String text2 = Float.toString(number);

Transforme un float en texte.

📌 Convertir un float vers un autre type


int i = (int) number;

double d = (double) number;

long l = (long) number;

Permet de convertir un float vers un autre type numérique.

Lors d'une conversion vers un int, la partie décimale est supprimée. 

float number = 10.9f;

int i = (int) number;

Résultat : 


10

📌 Valeur absolue


float abs = Math.abs(number);

Transforme un nombre négatif en nombre positif. 


Math.abs(-8.5f);

Résultat : 


8.5

📌 Plus grand nombre


float max = Math.max(number, 25f);

Retourne la plus grande des deux valeurs. 


Math.max(15f, 25f);

Résultat : 


25.0

📌 Plus petit nombre


float min = Math.min(number, 25f);

Retourne la plus petite des deux valeurs. 


Math.min(15f, 25f);

Résultat : 


15.0

📌 Puissance


double power = Math.pow(number, 2);

Élève un nombre à une puissance. 


Math.pow(5f, 2);

Résultat : 


25.0
Math.pow() retourne toujours un double, même si la valeur donnée est un float.

📌 Racine carrée


double root = Math.sqrt(number);

Calcule la racine carrée d'un nombre. 


Math.sqrt(25f);

Résultat : 


5.0

📌 Arrondir vers le bas


double floor = Math.floor(number);

Arrondit vers l'entier inférieur. 


Math.floor(7.9);

Résultat : 


7.0

📌 Arrondir vers le haut


double ceil = Math.ceil(number);

Arrondit vers l'entier supérieur. 


Math.ceil(7.1);

Résultat : 


8.0

📌 Arrondi classique


int round = Math.round(number);

Arrondit un nombre à l'entier le plus proche. 


Math.round(7.6f);

Résultat : 


8

📌 Vérifier si le nombre est NaN


Float.isNaN(number);

Vérifie si une valeur n'est pas un nombre (Not a Number).

Retourne :


true

false

📌 Vérifier si le nombre est infini


Float.isInfinite(number);

Vérifie si la valeur est positive ou négative infinie.

Retourne :


true

false

📌 Valeurs maximales


Float.MAX_VALUE

Float.MIN_VALUE

Float.MAX_VALUE représente la plus grande valeur positive qu'un float peut stocker.

Float.MIN_VALUE représente la plus petite valeur positive non nulle représentable par un float.

Float.MIN_VALUE n'est pas la plus petite valeur négative possible.

⭐ Bonnes pratiques

✔ Toujours ajouter le suffixe f aux nombres décimaux de type float.

✔ Utiliser double lorsqu'une meilleure précision est nécessaire.

✔ Utiliser la classe Math pour les calculs avancés.

✔ Faire attention aux conversions vers int : elles suppriment toujours les décimales.
