🌳 Conditions - Java

Les conditions permettent d'exécuter du code uniquement lorsqu'une expression est vraie. Elles sont utilisées pour créer des choix et différents comportements dans un programme.

📌 if


if(condition){

}
Le code à l'intérieur du if est exécuté uniquement si la condition vaut true.

Exemple :


if(age >= 18){

    System.out.println("Adult");

}

Si l'âge est supérieur ou égal à 18 : 


Adult

📌 if / else


if(condition){

}else{

}

Le else est exécuté lorsque la condition est fausse. 


if(score >= 50){

    System.out.println("Success");

}else{

    System.out.println("Failed");

}

📌 else if


if(condition){

}else if(condition){

}else{

}

Permet de tester plusieurs conditions différentes. 


if(score >= 90){

    System.out.println("A");

}else if(score >= 80){

    System.out.println("B");

}else{

    System.out.println("C");

}

📌 Opérateurs de comparaison


==  égal à

!=  différent de

>   supérieur à

<   inférieur à

>=  supérieur ou égal

<=  inférieur ou égal

Ils permettent de comparer des valeurs.

📌 Opérateurs logiques

ET (&&)


if(age >= 18 && hasLicense){

}

Les deux conditions doivent être vraies.

OU (||)


if(isAdmin || isOwner){

}

Une seule condition vraie suffit.

NON (!)


if(!isDead){

}

Inverse la valeur d'un booléen.

📌 Comparer une String

Il ne faut pas utiliser == pour comparer du texte. 


// Mauvais

if(name == "Yorin"){

}


// Correct

if(name.equals("Yorin")){

}

equals() compare le contenu du texte.

📌 switch


switch(day){

    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    default:
        System.out.println("Unknown");

}

Le switch permet de comparer une variable avec plusieurs valeurs possibles.

📌 Opérateur ternaire


String result = (score >= 50)
    ? "Success"
    : "Failed";

C'est une version courte d'un if / else.

⭐ Bonnes pratiques

✔ Utiliser equals() pour comparer des String.

✔ Utiliser switch lorsque beaucoup de valeurs sont possibles.

✔ Utiliser && quand toutes les conditions doivent être vraies.

✔ Utiliser || lorsqu'une seule condition suffit.

✔ Éviter les conditions trop imbriquées.
