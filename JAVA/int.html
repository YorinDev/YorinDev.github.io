🔢 Int - Java

Le int permet de stocker des nombres entiers, c'est-à-dire des nombres sans décimales. Il est utilisé pour représenter des valeurs comme un âge, un score ou une quantité. 


int age = 15;
Un int peut contenir des valeurs entre :

-2 147 483 648
et
2 147 483 647

📌 Déclaration


int number;

int number = 10;

Crée une variable qui contient un nombre entier.

📌 Addition


int result = number + 5;

Ajoute deux nombres ensemble. 


10 + 5

Résultat : 


15

📌 Soustraction


int result = number - 5;

Retire une valeur à un nombre.

📌 Multiplication


int result = number * 5;

Multiplie deux nombres.

📌 Division


int result = number / 3;
Avec un int, une division garde uniquement la partie entière.

Exemple :

10 / 3 donne :
3

La partie décimale est supprimée.

📌 Modulo (%)


int result = number % 3;

Retourne le reste d'une division. 


10 % 3

Résultat : 


1

📌 Vérifier si un nombre est pair


boolean even = number % 2 == 0;

Retourne true si le nombre est divisible par 2.

📌 Incrémentation


number++;

Ajoute 1 à une variable. 


number = number + 1;

📌 Décrémentation


number--;

Retire 1 à une variable. 


number = number - 1;

📌 Affectation simplifiée


number += 5;

number -= 5;

number *= 5;

number /= 5;

number %= 5;

Permet de modifier une variable plus rapidement.

📌 Comparaisons


number == 10

number != 10

number > 10

number < 10

number >= 10

number <= 10

Les comparaisons retournent toujours :


true

false

📌 Convertir une String en int


int value = Integer.parseInt("123");

Transforme un texte en nombre entier.

📌 Convertir un int en String


String text = String.valueOf(number);

Transforme un nombre en texte.

📌 Valeurs maximales


Integer.MAX_VALUE

Integer.MIN_VALUE

Integer.MAX_VALUE représente la plus grande valeur possible d'un int. 


2 147 483 647

Integer.MIN_VALUE représente la plus petite valeur possible. 


-2 147 483 648

📌 Fonctions Math utiles


Math.abs(number);

Math.max(15, 8);

Math.min(15, 8);

Math.pow(number, 2);

Math.sqrt(number);

Ces fonctions permettent de faire des calculs comme la valeur absolue, le maximum, le minimum, les puissances ou les racines carrées.

📌 Nombre aléatoire


int random = (int)(Math.random() * 100);

Génère un nombre aléatoire entre 0 et 99.

📌 Vérifier si un nombre est impair


boolean odd = number % 2 != 0;

Retourne true si le nombre n'est pas divisible par 2.

⭐ Bonnes pratiques

✔ Utiliser int pour les nombres entiers classiques.

✔ Utiliser double ou float pour les nombres avec décimales.

✔ Utiliser % pour vérifier si un nombre est pair ou impair.

✔ Attention : la division entre deux int supprime les décimales.

✔ Utiliser Integer.parseInt() pour convertir du texte en nombre.
