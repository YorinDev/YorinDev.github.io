📚 String - Java

Une String permet de stocker du texte.

Une String peut contenir des lettres, des chiffres, des symboles ou des espaces.

📌 Déclaration


String name;

String name = "Yorin";

String empty = "";

String text = new String("Hello");

Crée une variable contenant du texte.

📌 Obtenir la longueur


int length = name.length();

Retourne le nombre de caractères dans la String. 


"Hello".length();

Résultat : 


5

📌 Vérifier si une String est vide


boolean empty = name.isEmpty();

Vérifie si la String contient 0 caractère.

Retourne :

true si la String est vide.
false sinon.

📌 Vérifier si une String est vide ou contient seulement des espaces


boolean blank = name.isBlank();

Disponible depuis Java 11. 


"".isBlank();

Résultat : 


true



"   ".isBlank();

Résultat : 


true

📌 Obtenir un caractère


char c = name.charAt(0);

Retourne le caractère situé à un index précis. 


String name = "Yorin";

name.charAt(0);

Résultat : 


'Y'
Le premier index commence toujours à 0.

📌 Trouver l'index d'un texte


int index = name.indexOf("o");

Retourne la position de la première occurrence. 


"Yorin".indexOf("o");

Résultat : 


1

📌 Trouver l'index d'un caractère


int index = name.indexOf('o');

Fonctionne avec un caractère de type char.

📌 Chercher à partir d'un index


int index = name.indexOf("o", 2);

Commence la recherche à partir de l'index 2.

📌 Dernière occurrence


int lastIndex = name.lastIndexOf("o");

Retourne la dernière position où apparaît le texte. 


"banana".lastIndexOf("a");

Résultat : 


5

📌 Extraire une partie d'une String


String sub = name.substring(2);

Récupère tout le texte à partir de l'index donné. 


"Hello".substring(2);

Résultat : 


llo

📌 Extraire entre deux index


String sub = name.substring(2, 5);

Le premier index est inclus.

Le deuxième index est exclu. 


"Hello".substring(1, 4);

Résultat : 


ell

📌 Vérifier si une String contient un texte


boolean contains = name.contains("or");

Vérifie si un texte existe dans la String. 


"Yorin".contains("Yo");

Résultat : 


true

📌 Vérifier le début


boolean starts = name.startsWith("Yo");

Vérifie les premiers caractères d'une String.

📌 Vérifier la fin


boolean ends = name.endsWith("in");

Vérifie les derniers caractères d'une String.

📌 Comparer des String


boolean equal = name.equals("Yorin");

Compare le contenu de deux String.

Ne pas utiliser :

name == "Yorin"

Car == compare les références et non le texte.

📌 Ignorer les majuscules


boolean equalIgnore = name.equalsIgnoreCase("yorin");

Ignore la différence entre majuscules et minuscules. 


YORIN = yorin = Yorin

📌 Mettre en majuscules


String upper = name.toUpperCase();

Transforme tous les caractères en majuscules. 


yorin → YORIN

📌 Mettre en minuscules


String lower = name.toLowerCase();

Transforme tous les caractères en minuscules. 


YORIN → yorin

📌 Remplacer du texte


String replace = name.replace("Y", "J");

Remplace toutes les occurrences trouvées. 


"Hello".replace("l", "x");

Résultat : 


Hexxo

📌 Remplacer la première occurrence


String replaceFirst = name.replaceFirst("o", "a");

Remplace uniquement le premier élément trouvé.

📌 Remplacer avec une Regex


String replaceAll = name.replaceAll("o", "a");

Utilise les expressions régulières pour effectuer un remplacement.

📌 Supprimer les espaces


String trim = name.trim();

Supprime les espaces au début et à la fin.

📌 Supprimer les espaces (Java 11+)


String strip = name.strip();

Version améliorée de trim().

📌 Répéter une String


String repeat = name.repeat(3);

Répète une String plusieurs fois. 


"Hi".repeat(3);

Résultat : 


HiHiHi

📌 Concaténer des String


String full = name.concat(" Dev");

Ajoute du texte à la fin d'une String.

Autre méthode : 


String full2 = name + " Dev";

📌 Comparaison alphabétique


int compare = name.compareTo("Alex");

Compare l'ordre alphabétique de deux String. 


0  = identique

<0 = avant

>0 = après

📌 Convertir en tableau de caractères


char[] chars = name.toCharArray();

Transforme une String en tableau de char.

📌 Séparer une String


String[] split = name.split(",");

Découpe une String avec un séparateur. 


"A,B,C".split(",");

Résultat : 


[A, B, C]

📌 Joindre plusieurs String


String joined = String.join(", ", "A", "B", "C");

Permet de fusionner plusieurs String avec un séparateur.

Résultat : 


A, B, C

📌 Vérifier une Regex


boolean matches = name.matches("[A-Z][a-z]+");

Vérifie si une String respecte un modèle. 


Yorin ✅

yorin ❌

📌 Convertir en bytes


byte[] bytes = name.getBytes();

Transforme le texte en tableau de bytes.

Utilisé pour : 


- fichiers

- réseaux

- encodage

📌 Formater une String


String formatted = String.format(
    "Nom : %s | Age : %d",
    name,
    15
);

Permet d'insérer des valeurs dans un texte. 


Nom : Yorin | Age : 15

📌 Convertir une valeur en String


String value = String.valueOf(123);

String value2 = String.valueOf(true);

Transforme n'importe quelle valeur en texte.

📌 StringBuilder


StringBuilder builder = new StringBuilder();

builder.append("Hello");

builder.append(" World");

String result = builder.toString();

Plus performant que + pour beaucoup de concaténations.

📌 Retirer un préfixe ou suffixe (Java 11+)


String noPrefix = name.stripLeading();

String noSuffix = name.stripTrailing();

Supprime les espaces uniquement au début ou à la fin.

📌 Indentation (Java 12+)


String indented = name.indent(4);

Ajoute une indentation au texte.

📌 Traduire les échappements (Java 15+)


String translated = "\\nHello".translateEscapes();

Transforme les caractères échappés. 


\n

Devient un retour à la ligne.

📌 Lire chaque ligne (Java 11+)


name.lines()
.forEach(System.out::println);

Permet de parcourir chaque ligne d'une String.

📌 Parcourir chaque caractère


for(int i = 0; i < name.length(); i++){

    char letter = name.charAt(i);

}

Parcourt tous les caractères présents dans une String.

📌 Vérifier si une String est null ou vide


if(name == null || name.isEmpty()){

}

Vérifie si la String n'existe pas ou si elle ne contient aucun caractère.

Permet d'éviter une erreur lorsque la variable vaut null.

📌 Vérifier si une String est null ou blanche


if(name == null || name.isBlank()){

}

Vérifie si la String est absente ou contient uniquement des espaces.

💡 Bonnes pratiques

✔ Utiliser equals() pour comparer des String.

✔ Utiliser StringBuilder pour beaucoup de modifications.

✔ Toujours vérifier null avant d'utiliser une String.

✔ Se rappeler que les index commencent à 0.

✔ Les String sont immuables : les méthodes créent une nouvelle String au lieu de modifier l'ancienne.
