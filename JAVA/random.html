🎲 Random - Java

La classe Random permet de générer des valeurs aléatoires comme des nombres, des booléens ou des valeurs décimales.

📌 Importer Random


import java.util.Random;

Permet d'utiliser la classe Random dans un programme Java.

📌 Créer un Random


Random random = new Random();

Crée un générateur de nombres aléatoires.

En général, un seul objet Random suffit pour tout le programme.

📌 Nombre entier aléatoire


int number = random.nextInt();

Génère un entier aléatoire de type int.

La valeur peut être positive ou négative.

📌 Nombre entre 0 et 99


int number = random.nextInt(100);

Résultat possible : 


0 → 99
Le minimum est inclus.

Le maximum est exclu.

📌 Nombre entre 1 et 100


int number = random.nextInt(100) + 1;

Résultat possible : 


1 → 100

On ajoute 1 pour décaler les valeurs obtenues.

📌 Nombre entre deux valeurs


int number = random.nextInt(max - min + 1) + min;

Cette formule permet de générer un entier entre deux valeurs incluses.

Exemple : 


int number = random.nextInt(51) + 50;

Résultat : 


50 → 100
Cette formule fonctionne sur les anciennes versions de Java.

📌 Java 17+ : méthode simplifiée


int number = random.nextInt(10, 20);

Résultat : 


10 → 19

Le premier nombre est inclus.

Le deuxième nombre est exclu. 


int number = random.nextInt(1, 101);

Résultat : 


1 → 100

📌 Nombre décimal


double number = random.nextDouble();

Génère un nombre décimal entre : 


0.0 → 1.0
La valeur 1.0 n'est jamais obtenue.

📌 Nombre décimal entre 0 et 100


double number = random.nextDouble() * 100;

Multiplie le résultat pour obtenir une valeur plus grande. 


0.0 → 100.0

📌 Float aléatoire


float number = random.nextFloat();

Retourne un nombre décimal de type float. 


0.0f → 1.0f

📌 Booléen aléatoire


boolean value = random.nextBoolean();

Retourne une valeur aléatoire : 


true

false

📌 Long aléatoire


long value = random.nextLong();

Génère une valeur aléatoire de type long.

📌 Choisir un élément dans un tableau


String[] fruits = {"Pomme", "Poire", "Banane"};

String fruit = fruits[random.nextInt(fruits.length)];

Permet de choisir un élément au hasard dans un tableau.

Le nombre généré correspond à l'index d'un élément du tableau.

📌 Choisir un élément dans une ArrayList


String fruit = fruits.get(random.nextInt(fruits.size()));

Permet de sélectionner un élément aléatoire dans une ArrayList.

size() retourne le nombre d'éléments présents dans la liste.

📌 Générer plusieurs nombres


for(int i = 0; i < 5; i++){

    System.out.println(random.nextInt(10));

}

Affiche 5 nombres aléatoires compris entre : 


0 → 9

📌 Définir une seed


Random random = new Random(12345);

Une seed permet de définir le point de départ du générateur aléatoire.

Avec la même seed, Java génère toujours la même suite de nombres.

Les seeds sont utiles pour : 


- les tests

- la génération procédurale

- reproduire un résultat précis

📌 Méthodes les plus utilisées


random.nextInt();

random.nextInt(max);


random.nextDouble();


random.nextFloat();


random.nextBoolean();


random.nextLong();

Ces méthodes permettent de générer les valeurs aléatoires les plus courantes.

⚠ Erreur fréquente


random.nextInt(10);

Résultat possible : 


0 → 9
Le maximum est toujours exclu avec nextInt(max).

Pour obtenir : 


1 → 10

Il faut utiliser : 


random.nextInt(10) + 1;

📚 Différence entre Random et Math.random()


Math.random();

Retourne uniquement un nombre décimal entre : 


0.0 → 1.0

Alors que Random permet de générer plusieurs types de valeurs : 


int

double

float

boolean

long
La classe Random est généralement plus pratique pour les programmes nécessitant plusieurs valeurs aléatoires.

⭐ Bonnes pratiques

✔ Créer un seul objet Random et le réutiliser.

✔ Utiliser nextInt(max - min + 1) + min pour les anciennes versions de Java.

✔ Utiliser nextInt(min, max) avec Java 17 ou plus récent.

✔ Toujours vérifier que le maximum est exclu avec nextInt(max).

✔ Utiliser une seed uniquement lorsque vous voulez reproduire un résultat précis.
