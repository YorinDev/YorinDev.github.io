⌨️ Scanner - Java

Le Scanner permet de récupérer les informations écrites par l'utilisateur dans la console. Il est principalement utilisé pour créer des programmes interactifs.

📌 Importer Scanner


import java.util.Scanner;

Permet d'utiliser la classe Scanner.

📌 Créer un Scanner


Scanner scanner = new Scanner(System.in);

Crée un lecteur qui récupère les entrées du clavier.

System.in représente ce que l'utilisateur écrit dans la console.

📌 Lire une ligne complète


String text = scanner.nextLine();

Attend que l'utilisateur appuie sur Entrée et récupère toute la ligne, y compris les espaces.

Exemple, l'utilisateur écrit : 


Bonjour tout le monde

Résultat : 


text = "Bonjour tout le monde";

📌 Lire un seul mot


String word = scanner.next();

Lit uniquement jusqu'au prochain espace.

Exemple :


Bonjour tout le monde

Résultat :


word = "Bonjour";

📌 Lire un entier


int number = scanner.nextInt();

Lit un nombre entier. 


42

Résultat :


number = 42;

📌 Lire un nombre décimal


double price = scanner.nextDouble();

Lit un nombre avec des décimales. 


10.99

Résultat :


price = 10.99;

📌 Lire un float


float value = scanner.nextFloat();

Lit un nombre décimal de type float.

📌 Lire un long


long value = scanner.nextLong();

Lit un nombre entier pouvant contenir de très grandes valeurs.

📌 Lire un short


short value = scanner.nextShort();

Lit un petit nombre entier.

📌 Lire un byte


byte value = scanner.nextByte();

Lit une petite valeur entière.

📌 Lire un booléen


boolean answer = scanner.nextBoolean();

L'utilisateur doit écrire : 


true

false

Exemple :


boolean isAdmin = scanner.nextBoolean();

📌 Lire un caractère


char letter = scanner.next().charAt(0);

La classe Scanner ne possède pas de méthode nextChar().

On récupère donc le premier caractère du texte.

Exemple, l'utilisateur écrit : 


A

Résultat : 


letter = 'A';

📌 Vérifier un entier avant de le lire


if(scanner.hasNextInt()){

    int number = scanner.nextInt();

}

Vérifie que l'utilisateur a bien écrit un entier avant de le récupérer.

Cela permet d'éviter des erreurs lorsque l'utilisateur écrit une valeur incorrecte.

📌 Vérifier un double


if(scanner.hasNextDouble()){

    double number = scanner.nextDouble();

}

Vérifie qu'un nombre décimal peut être lu.

📌 Vérifier un booléen


if(scanner.hasNextBoolean()){

    boolean answer = scanner.nextBoolean();

}

Vérifie que l'entrée correspond à : 


true

false

📌 Demander une information


System.out.print("Your name : ");

String name = scanner.nextLine();

System.out.println("Hello " + name);

Demande une réponse à l'utilisateur puis l'affiche.

Exemple : 


Your name : Alex

Hello Alex

📌 Fermer le Scanner


scanner.close();
Après avoir utilisé close(), le Scanner ne peut plus être utilisé.

⚠ nextInt() + nextLine()

Un problème courant arrive lorsque l'on mélange nextInt() et nextLine(). 


int age = scanner.nextInt();

String name = scanner.nextLine();

Le problème vient du fait que nextInt() ne récupère pas le retour à la ligne (\n) après le nombre.

Le prochain nextLine() récupère alors uniquement le reste de la ligne vide.

✅ Solution


int age = scanner.nextInt();

scanner.nextLine();

String name = scanner.nextLine();

Le premier nextLine() récupère l'Entrée restante avant de lire le vrai texte.

📌 Exemple complet


import java.util.Scanner;

public class Main {

    public static void main(String[] args){

        Scanner scanner = new Scanner(System.in);

        System.out.print("Name : ");

        String name = scanner.nextLine();


        System.out.print("Age : ");

        int age = scanner.nextInt();


        System.out.println("Hello " + name);

        System.out.println("You are " + age + " years old.");


        scanner.close();

    }

}

Résultat : 


Name : Alex
Age : 15

Hello Alex
You are 15 years old.

📚 Méthodes les plus utilisées


scanner.nextLine();

Lit une ligne complète. 


scanner.next();

Lit un seul mot. 


scanner.nextInt();

Lit un entier. 


scanner.nextDouble();

Lit un nombre décimal. 


scanner.nextFloat();

Lit un float. 


scanner.nextBoolean();

Lit une valeur true ou false. 


scanner.hasNextInt();

Vérifie un entier. 


scanner.hasNextDouble();

Vérifie un double. 


scanner.close();

Ferme le Scanner.

⭐ Bonnes pratiques

✔ Toujours fermer le Scanner quand le programme est terminé.

✔ Utiliser nextLine() pour lire des phrases complètes.

✔ Utiliser next() pour lire un seul mot.

✔ Vérifier avec hasNextInt() ou hasNextDouble() avant de récupérer une valeur utilisateur.

✔ Faire attention au mélange entre nextInt() et nextLine().
