🔢 Double - Java

Le double permet de stocker des nombres décimaux avec une grande précision. Il est utilisé pour représenter des valeurs comme des prix, des mesures ou des calculs nécessitant des nombres après la virgule. 


double price = 10.5;
Contrairement au float, un double n'a pas besoin du suffixe d lors de sa déclaration.

📌 Déclaration


double number = 10.5;

Stocke un nombre avec des décimales. 


double pi = 3.14159;

double price = 19.99;

📌 Calculs


number + 5.2;

number - 5.2;

number * 2;

number / 2;

Permet d'effectuer des opérations mathématiques avec des nombres décimaux. 


double result = 10.5 + 2.5;

Résultat : 


13.0

📌 Modulo (%)


number % 2;

Retourne le reste d'une division. 


10.5 % 2;

Résultat : 


0.5

📌 Affectation simplifiée


number += 2.5;

number -= 2.5;

number *= 2;

number /= 2;

Permet de modifier une variable plus rapidement. 


number += 5;

Équivaut à :


number = number + 5;

📌 Comparaisons


number == 10.5

number != 10.5

number > 5

number < 5

number >= 5

number <= 5

Les comparaisons retournent :


true

false



if(number >= 10){

    System.out.println("High");

}

📌 Arrondir vers le bas


Math.floor(number);

Arrondit un nombre vers l'entier inférieur. 


Math.floor(10.9);

Résultat : 


10.0

📌 Arrondir vers le haut


Math.ceil(number);

Arrondit un nombre vers l'entier supérieur. 


Math.ceil(10.1);

Résultat : 


11.0

📌 Arrondi classique


Math.round(number);

Arrondit vers l'entier le plus proche. 


Math.round(10.4);

Résultat : 


10



Math.round(10.6);

Résultat : 


11

📌 Valeur absolue


Math.abs(number);

Transforme un nombre négatif en nombre positif. 


Math.abs(-15.5);

Résultat : 


15.5

📌 Plus grand nombre


Math.max(12.4, 18.9);

Retourne la plus grande valeur. 


18.9

📌 Plus petit nombre


Math.min(12.4, 18.9);

Retourne la plus petite valeur. 


12.4

📌 Puissance


Math.pow(number, 3);

Élève un nombre à une puissance. 


Math.pow(5, 3);

Résultat : 


125.0

Car : 


5 × 5 × 5 = 125

📌 Racine carrée


Math.sqrt(number);

Calcule la racine carrée d'un nombre. 


Math.sqrt(25);

Résultat : 


5.0

📌 Sinus


Math.sin(number);

Calcule le sinus d'un angle.

La valeur doit être donnée en radians.

Utilisé notamment pour :
- les rotations
- les mouvements circulaires
- les calculs physiques

📌 Cosinus


Math.cos(number);

Calcule le cosinus d'un angle.

Utilisé pour les calculs d'angles et de positions.

📌 Tangente


Math.tan(number);

Calcule la tangente d'un angle.

Principalement utilisée en géométrie et dans les calculs 3D.

📌 Convertir une String en double


double value = Double.parseDouble("15.8");

Transforme un texte en nombre décimal. 


String text = "20.5";

double number = Double.parseDouble(text);

Résultat : 


20.5

📌 Convertir un double en String


String text = String.valueOf(number);

Transforme un nombre en texte. 


double price = 10.99;

String text = String.valueOf(price);

Résultat : 


"10.99"

📌 Vérifier si le nombre est NaN


Double.isNaN(number);

Vérifie si la valeur n'est pas un nombre (Not a Number). 


double value = 0.0 / 0.0;

Double.isNaN(value);

Résultat : 


true

📌 Vérifier si le nombre est infini


Double.isInfinite(number);

Vérifie si un nombre est positif ou négatif infini. 


double value = 1.0 / 0.0;

Double.isInfinite(value);

Résultat : 


true

📌 Valeurs maximales


Double.MAX_VALUE

Double.MIN_VALUE

Double.MAX_VALUE représente le plus grand nombre positif qu'un double peut stocker.

Double.MIN_VALUE représente le plus petit nombre positif non nul qu'un double peut stocker.

⭐ Bonnes pratiques

✔ Utiliser double pour les nombres décimaux nécessitant une bonne précision.

✔ Utiliser float uniquement lorsque la mémoire est une contrainte importante.

✔ Éviter de comparer des double avec == dans les calculs complexes à cause des erreurs de précision.

✔ Utiliser la classe Math pour les opérations avancées.
