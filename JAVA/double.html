🔢 Double - Java

Le double permet de stocker des nombres décimaux avec une grande précision. Il est utilisé pour représenter des valeurs comme des prix, des mesures ou des calculs nécessitant des nombres après la virgule. 


double price = 10.5;
Contrairement au float, un double n'a pas besoin du suffixe d lors de sa déclaration.

📌 Déclaration


double number = 10.5;

Stocke un nombre avec des décimales. 


double pi = 3.14159;

double price = 19.99;

📌 Calculs


number + 5.2;

number - 5.2;

number * 2;

number / 2;

Permet d'effectuer des opérations mathématiques avec des nombres décimaux. 


double result = 10.5 + 2.5;

Résultat : 


13.0

📌 Modulo (%)


number % 2;

Retourne le reste d'une division. 


10.5 % 2;

Résultat : 


0.5

📌 Affectation simplifiée


number += 2.5;

number -= 2.5;

number *= 2;

number /= 2;

Permet de modifier une variable plus rapidement. 


number += 5;

Équivaut à :


number = number + 5;

📌 Comparaisons


number == 10.5

number != 10.5

number > 5

number < 5

number >= 5

number <= 5

true

false
