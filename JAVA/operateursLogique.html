🧠 Opérateurs logiques - Java

Les opérateurs logiques permettent de combiner plusieurs conditions. Ils sont principalement utilisés avec les if, while, for et les valeurs booléennes.

Les résultats des opérateurs logiques sont toujours :

true
ou
false

📌 ET logique (&&)


condition1 && condition2

Les deux conditions doivent être vraies pour obtenir true. 


true  && true  = true

true  && false = false

false && true  = false

false && false = false

Exemple


int age = 20;

boolean hasLicense = true;


if(age >= 18 && hasLicense){

    System.out.println("Can drive");

}

Résultat : 


Can drive

Car :


age >= 18 → true

hasLicense → true

📌 OU logique (||)


condition1 || condition2

Une seule condition doit être vraie pour obtenir true. 


true  || true  = true

true  || false = true

false || true  = true

false || false = false

Exemple


boolean isAdmin = false;

boolean isOwner = true;


if(isAdmin || isOwner){

    System.out.println("Access granted");

}

Résultat : 


Access granted

Car :


isOwner = true

📌 NON logique (!)


!condition

Inverse une valeur booléenne. 


!true  = false

!false = true

Exemple


boolean isDead = false;


if(!isDead){

    System.out.println("Player alive");

}

Résultat : 


Player alive

Car :


!false = true

📌 Combiner plusieurs opérateurs

Les opérateurs peuvent être utilisés ensemble dans une même condition. 


if(age >= 18 && hasLicense || isAdmin){

}
Java lit les opérateurs dans cet ordre :

1. ! (NON)
2. && (ET)
3. || (OU) 

age >= 18 && hasLicense || isAdmin

Équivaut à : 


(age >= 18 && hasLicense) || isAdmin

📌 Utiliser des parenthèses

Les parenthèses permettent de contrôler l'ordre d'évaluation des conditions. 


if(age >= 18 && (hasLicense || isAdmin)){

}

Ici Java vérifie d'abord : 


(hasLicense || isAdmin)

Puis vérifie : 


age >= 18
Les parenthèses permettent de rendre une condition complexe plus claire et d'éviter les erreurs de logique.

📌 Opérateur logique avec des variables


boolean hasMoney = true;

boolean hasTicket = false;


if(hasMoney && hasTicket){

    System.out.println("Enter");

}

Résultat : 


Pas d'affichage

Car :


true && false = false

📌 Vérifier plusieurs choix

L'opérateur || permet d'accepter plusieurs valeurs possibles. 


String rank = "Admin";


if(rank.equals("Admin") || rank.equals("Moderator")){

    System.out.println("Staff");

}

Si le grade est Admin ou Moderator, la condition est vraie.

📌 Vérifier plusieurs conditions obligatoires

L'opérateur && permet d'exiger plusieurs conditions. 


int level = 50;

int coins = 1000;


if(level >= 50 && coins >= 1000){

    System.out.println("Unlocked");

}

Les deux conditions doivent être respectées pour exécuter le code.

📌 Inverser une condition

Sans utiliser ! : 


if(isOnline == false){

}

Avec ! : 


if(!isOnline){

}

Les deux conditions produisent le même résultat.

📌 Double négation (!!)


!!value

Transforme une valeur en booléen. 


boolean result = !!true;

Résultat : 


true
La double négation est rarement nécessaire en Java.

📌 Opérateur logique avec null

Il est possible d'utiliser && pour éviter des erreurs avec les valeurs nulles. 


if(name != null && name.equals("Yorin")){

}

La première condition vérifie que name existe avant d'utiliser equals().

Sans cette vérification, appeler une méthode sur une valeur null peut provoquer une erreur :

NullPointerException

📌 Court-circuit (Short-Circuit)

Java n'évalue pas toujours toutes les conditions. 


if(false && test()){

}

La fonction test() ne sera jamais exécutée. 


false && quelque chose = false

Avec || : 


if(true || test()){

}

La fonction test() ne sera pas exécutée. 


true || quelque chose = true
Le court-circuit permet d'éviter des calculs inutiles et peut empêcher certaines erreurs.

📚 Résumé des opérateurs


&&

➡ ET logique
➡ Toutes les conditions doivent être vraies. 


||

➡ OU logique
➡ Une seule condition vraie suffit. 


!

➡ NON logique
➡ Inverse une valeur booléenne.

⭐ Bonnes pratiques

✔ Utiliser && lorsque toutes les conditions sont obligatoires.

✔ Utiliser || lorsqu'une seule condition suffit.

✔ Utiliser ! pour simplifier les vérifications de booléens.

✔ Utiliser des parenthèses lorsque les conditions deviennent complexes.

✔ Profiter du court-circuit pour éviter des erreurs avec null.
