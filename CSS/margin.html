📏 Margin - CSS

La propriété margin permet de créer un espace extérieur autour d'un élément. Elle contrôle la distance entre un élément et les autres éléments de la page.

La marge est située à l'extérieur de l'élément, contrairement au padding qui ajoute de l'espace à l'intérieur.

📌 La propriété margin


.element{

    margin:20px;

}

Cette règle ajoute une marge de 20 pixels autour de l'élément. 


+-------------------+

        margin

   +-------------+
   |             |
   |  element    |
   |             |
   +-------------+

        margin

+-------------------+

📌 Les quatre côtés

Avec une seule valeur, la marge est appliquée aux quatre côtés : 


.element{

    margin:

        20px;

}

Cela équivaut à : 


.element{

    margin-top:

        20px;


    margin-right:

        20px;


    margin-bottom:

        20px;


    margin-left:

        20px;

}

📌 margin-top

Définit la marge supérieure d'un élément. 


.box{

    margin-top:

        50px;

}

L'élément sera déplacé de 50 pixels vers le bas par rapport aux éléments précédents.

📌 margin-right

Définit la marge à droite. 


.box{

    margin-right:

        30px;

}

📌 margin-bottom

Définit l'espace sous un élément. 


.box{

    margin-bottom:

        40px;

}

Très utilisé pour espacer les titres, paragraphes et sections.

📌 margin-left

Définit la marge à gauche. 


.box{

    margin-left:

        25px;

}

📌 Écrire plusieurs valeurs

La propriété margin accepte plusieurs valeurs pour contrôler chaque côté. 


.element{

    margin:

        10px 20px;

}

Avec deux valeurs : 


10px

↓

Haut + Bas



20px

↓

Gauche + Droite

📌 Trois valeurs


.element{

    margin:

        10px 20px 30px;

}

Avec trois valeurs : 


10px

↓

Haut



20px

↓

Gauche + Droite



30px

↓

Bas

📌 Quatre valeurs


.element{

    margin:

        10px 20px 30px 40px;

}

L'ordre est toujours : 


Haut

↓

Droite

↓

Bas

↓

Gauche
Astuce : retenez l'ordre avec TRBL :

Top → haut
Right → droite
Bottom → bas
Left → gauche

📌 Centrer un élément avec margin auto

La valeur auto permet de centrer horizontalement un élément. 


.box{

    width:

        500px;


    margin:

        0 auto;

}

Le navigateur calcule automatiquement la marge gauche et droite pour centrer l'élément. 


margin:

    0 auto;


=

margin-top:

    0;


margin-bottom:

    0;


margin-left:

    auto;


margin-right:

    auto;

📌 Exemple de centrage


.container{

    width:

        800px;

}



.card{

    width:

        300px;


    margin:

        0 auto;

}

La carte sera placée au centre du conteneur.

📌 Margin avec des pourcentages

Les marges peuvent aussi utiliser des pourcentages. 


.box{

    margin:

        10%;

}

Le pourcentage est calculé par rapport à la largeur du parent.

📌 Margin avec des unités relatives


.box{

    margin:

        2rem;

}

Les unités courantes : 


px

Valeur fixe en pixels



%

Pourcentage du parent



rem

Basé sur la taille de police racine



em

Basé sur la taille de police de l'élément

📌 Différence entre margin et padding


margin

↓

Espace extérieur


+----------------+

|                |

|    padding     |

|   +--------+   |

|   |contenu |   |

|   +--------+   |

|                |

+----------------+

↓

margin

Margin contrôle l'espace entre les éléments.

Padding contrôle l'espace entre le contenu et la bordure.

📌 Exemple avec border


.box{

    padding:

        20px;


    margin:

        30px;


    border:

        2px solid white;

}

Résultat : 


30px margin

+--------------------+

|  20px padding      |

| +--------------+   |

| |   contenu    |   |

| +--------------+   |

+--------------------+

📌 Supprimer une marge

Pour supprimer une marge existante : 


.element{

    margin:

        0;

}

Très utilisé pour enlever les marges par défaut du navigateur. 


body{

    margin:

        0;

}

Cela permet de repartir d'une page sans espace automatique autour du contenu.

📌 Les marges négatives

CSS permet d'utiliser des valeurs négatives avec margin. Cela permet de rapprocher ou superposer des éléments. 


.box{

    margin-top:

        -20px;

}

L'élément remontera de 20 pixels vers l'élément précédent.

Les marges négatives doivent être utilisées avec précaution car elles peuvent créer des problèmes de mise en page.

📌 Exemple de marge négative


.title{

    margin-bottom:

        -10px;

}



.image{

    margin-top:

        -20px;

}

L'image pourra remonter et se rapprocher du titre.

📌 Le problème des marges qui fusionnent

CSS possède un comportement appelé margin collapsing (fusion des marges). Lorsque deux marges verticales se rencontrent, elles peuvent fusionner. 


.title{

    margin-bottom:

        40px;

}



.text{

    margin-top:

        30px;

}

On pourrait penser obtenir : 


40px + 30px = 70px

Mais CSS applique généralement la plus grande valeur : 


40px

📌 Éviter le margin collapsing

Plusieurs solutions existent : 


.container{

    display:

        flex;

}

Flexbox empêche la fusion des marges entre les enfants. 


.container{

    padding:

        1px;

}

Ajouter un padding crée une séparation entre les éléments. 


.container{

    overflow:

        hidden;

}

L'overflow peut également empêcher certains comportements de fusion.

📌 Margin dans Flexbox

Les marges fonctionnent aussi avec Flexbox. 


.container{

    display:

        flex;

}



.item{

    margin:

        10px;

}

Chaque élément aura un espace autour de lui.

📌 Centrer avec margin auto en Flexbox


.container{

    display:

        flex;

}



.item{

    margin:

        auto;

}

L'élément sera centré dans son conteneur Flexbox.

📌 Exemple de menu avec margin


.nav{

    display:

        flex;

}



.logo{

    margin-right:

        auto;

}

Cette technique pousse les autres éléments vers la droite. 


Logo                    Liens

[LOGO]              [Accueil] [Contact]

📌 Margin et responsive design

Les marges doivent être adaptées aux différentes tailles d'écran. 


.card{

    margin:

        40px;

}



@media(max-width:700px){

    .card{

        margin:

            15px;

    }

}

Sur mobile, une marge plus petite permet de garder plus d'espace pour le contenu.

📌 Utiliser clamp() avec margin

La fonction clamp() permet d'avoir une marge qui s'adapte automatiquement. 


.section{

    margin:

        clamp(
            20px,
            5vw,
            80px
        );

}

La marge sera :

✔ Minimum : 20 pixels.
✔ Variable : 5% de la largeur de l'écran.
✔ Maximum : 80 pixels.

📌 Erreurs fréquentes

❌ Utiliser trop de marges fixes qui cassent le responsive.

❌ Confondre margin et padding.

❌ Utiliser des marges négatives sans raison.

❌ Ajouter des marges partout au lieu d'utiliser Flexbox ou Grid.

❌ Oublier les marges par défaut du navigateur.

⭐ Bonnes pratiques

✔ Utiliser margin:0 auto pour centrer les blocs.

✔ Préférer gap avec Flexbox et Grid pour espacer les éléments.

✔ Utiliser des unités relatives pour les designs adaptatifs.

✔ Garder une structure claire avec des espacements réguliers.

✔ Éviter les marges négatives sauf lorsque c'est nécessaire.

📌 Résumé

margin ajoute un espace extérieur autour d'un élément.

margin-top contrôle la marge supérieure.
margin-right contrôle la marge droite.
margin-bottom contrôle la marge inférieure.
margin-left contrôle la marge gauche.
margin:auto permet de centrer automatiquement.
margin négatif permet de rapprocher des éléments.
margin fonctionne avec Flexbox et Grid.

La propriété margin est essentielle pour organiser les espacements d'une page CSS.
