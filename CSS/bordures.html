🟦 Bordures - CSS

Les bordures permettent d'ajouter un contour autour d'un élément. Il est possible de modifier leur épaisseur, leur style, leur couleur ou encore d'arrondir les coins.

📌 Ajouter une bordure


div{

    border:2px solid black;

}
La propriété border regroupe l'épaisseur, le style et la couleur.

📌 Épaisseur


div{

    border-width:5px;

}

Définit l'épaisseur de la bordure.

📌 Style


div{

    border-style:dashed;

}

Quelques styles disponibles : 


solid

dashed

dotted

double

groove

ridge

inset

outset

none

📌 Couleur


div{

    border-color:#00bfff;

}

Permet de modifier la couleur de la bordure.

📌 Arrondir les coins


div{

    border-radius:15px;

}

Plus la valeur est élevée, plus les coins sont arrondis.

📌 Cercle parfait


div{

    width:150px;
    height:150px;

    border-radius:50%;

}

Avec une largeur et une hauteur identiques, on obtient un cercle.

📌 Bordure d'un seul côté


div{

    border-top:3px solid red;

}

On peut utiliser : 


border-top

border-right

border-bottom

border-left

📌 Bordures différentes


div{

    border-top:4px solid red;

    border-right:4px solid blue;

    border-bottom:4px solid green;

    border-left:4px solid orange;

}

Chaque côté peut avoir une couleur, une épaisseur ou un style différent.

📌 Exemple complet


.card{

    border:2px solid #00bfff;

    border-radius:12px;

    padding:20px;

}

Très utilisé pour créer des cartes ou des panneaux modernes.

⭐ Bonnes pratiques

✔ Utiliser border lorsque tous les côtés sont identiques.

✔ Utiliser border-radius pour un design plus moderne.

✔ Éviter des bordures trop épaisses.

✔ Choisir une couleur qui contraste avec le fond.

✔ Utiliser des bordures discrètes pour améliorer la lisibilité.
