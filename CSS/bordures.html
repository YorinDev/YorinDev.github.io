🖼️ Bordures - CSS

Les bordures permettent d'ajouter une ligne autour des éléments HTML. Elles sont utilisées pour créer des cartes, des boutons, des cadres ou séparer différentes parties d'une page.

📌 La propriété border


element{

    border:
        largeur
        style
        couleur;

}
La propriété border est une propriété raccourcie permettant de définir plusieurs propriétés de bordure en une seule ligne. 

div{

    border:

        2px solid black;

}

Cet exemple crée une bordure noire de 2 pixels autour du div.

📌 border-width


div{

    border-width:

        5px;

}

La propriété border-width définit l'épaisseur de la bordure. 


border-width:

    thin;


border-width:

    medium;


border-width:

    thick;

Il est également possible d'utiliser des pixels : 


div{

    border-width:

        10px;

}

📌 border-style


div{

    border-style:

        solid;

}

La propriété border-style définit l'apparence de la bordure. 


solid

────────


dashed

- - - - -


dotted

· · · · ·


double

══════


none

Aucune bordure

📌 border-color


div{

    border-color:

        red;

}

La propriété border-color permet de modifier la couleur de la bordure. 


.card{

    border:

        2px solid #00bfff;

}

📌 Les quatre côtés


div{

    border-top:

        2px solid red;


    border-right:

        2px solid blue;


    border-bottom:

        2px solid green;


    border-left:

        2px solid yellow;

}

Chaque côté peut avoir une bordure différente.

📌 border-top / right / bottom / left


div{

    border-top:

        3px solid white;

}

Ces propriétés permettent de modifier uniquement un côté.

📌 Style différent par côté


.box{

    border-width:

        5px;


    border-style:

        solid;


    border-color:

        red;

}

Il est aussi possible de définir plusieurs valeurs. 


.box{

    border-width:

        5px 10px 15px 20px;

}

L'ordre est :

haut → droite → bas → gauche

📌 border-radius


div{

    border-radius:

        20px;

}

La propriété border-radius permet d'arrondir les coins d'un élément. 


.card{

    background:

        #00bfff;


    border-radius:

        15px;

}
Cette propriété est très utilisée pour créer des interfaces modernes avec des cartes et des boutons arrondis.

📌 Cercle avec border-radius


.avatar{

    width:

        100px;


    height:

        100px;


    border-radius:

        50%;

}

Lorsque la largeur et la hauteur sont identiques, 50% crée un cercle.

📌 Plusieurs valeurs de radius


.box{

    border-radius:

        20px 0 20px 0;

}

L'ordre est :

haut gauche → haut droite → bas droite → bas gauche

📌 border-image


div{

    border-image:

        url("border.png");

}

La propriété border-image permet d'utiliser une image comme bordure.

Cette propriété est moins utilisée aujourd'hui que les bordures classiques ou les effets avec gradients.

📌 outline


div{

    outline:

        3px solid red;

}

La propriété outline ajoute une ligne autour d'un élément.

Contrairement à border, l'outline ne prend pas de place dans la taille de l'élément.

📌 Différence border et outline


border

✔ Fait partie de l'élément

✔ Peut modifier la taille


outline

✔ À l'extérieur

✔ Ne modifie pas la taille

📌 Bordures avec transparence


.card{

    border:

        1px solid rgba(
            255,
            255,
            255,
            .2
        );

}

Les couleurs RGBA permettent de créer des bordures transparentes.

📌 Bordure avec gradient


.box{

    border:

        2px solid transparent;


    background:

        linear-gradient(
            black,
            black
        )
        padding-box,


        linear-gradient(
            red,
            blue
        )
        border-box;

}

Cette technique permet de créer des bordures avec des dégradés.

⭐ Bonnes pratiques

✔ Utiliser des bordures fines pour les interfaces modernes.

✔ Utiliser border-radius pour améliorer le design.

✔ Utiliser RGBA pour des bordures transparentes.

✔ Garder une cohérence entre les couleurs des bordures.

✔ Éviter de mettre trop de bordures sur une page.

📌 Résumé

border permet de créer une bordure complète.

border-width contrôle l'épaisseur.
border-style contrôle le style.
border-color contrôle la couleur.
border-radius arrondit les coins.
outline ajoute une ligne extérieure.

Les bordures sont essentielles pour créer des interfaces propres et modernes.
