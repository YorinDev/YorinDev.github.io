🎯 Sélecteurs - CSS

Les sélecteurs CSS permettent de cibler des éléments HTML afin de leur appliquer des styles. Ils indiquent au navigateur quels éléments doivent être modifiés.

Sans sélecteur, CSS ne sait pas sur quels éléments appliquer les propriétés.

📌 Sélecteur universel (*)

Le sélecteur universel cible tous les éléments présents dans la page. 


*{

    margin:

        0;


    padding:

        0;

}

Cet exemple supprime les marges et espacements par défaut de tous les éléments.

📌 Sélecteur de balise

Il permet de cibler directement une balise HTML. 


p{

    color:

        white;

}

Tous les éléments <p> auront une couleur blanche. 


<p>

Texte

</p>


↓

CSS applique le style

📌 Sélecteur de classe (.)

Une classe permet d'appliquer un style à plusieurs éléments. 


.card{

    background:

        #222;

}

En HTML : 


<div class="card">

Carte

</div>
Une classe commence toujours par un point . en CSS.

📌 Sélecteur d'identifiant (#)

Un identifiant cible un élément unique. 


#title{

    color:

        red;

}

En HTML : 


<h1 id="title">

Titre

</h1>

Un id ne doit normalement être utilisé qu'une seule fois dans une page.

📌 Différence entre classe et id


Classe

.

↓

Plusieurs éléments



Id

#

↓

Un seul élément




// Classe

.card{

}



// Id

#header{

}

📌 Sélecteur descendant

Il permet de cibler un élément situé à l'intérieur d'un autre élément. 


.container p{

    color:

        gray;

}

Tous les paragraphes contenus dans .container seront modifiés. 





    

        Texte ciblé

📌 Sélecteur enfant direct (>)

Le symbole > cible uniquement les enfants directs d'un élément. 


.menu > a{

    color:

        cyan;

}

Seuls les liens directement placés dans .menu seront sélectionnés. 


.menu

 ├── a   ✔ ciblé

 └── div

      └── a   ❌ non ciblé

📌 Sélecteur frère adjacent (+)

Le symbole + cible l'élément placé juste après un autre élément. 


h2 + p{

    color:

        gray;

}

Ici, seul le premier paragraphe après un titre h2 sera sélectionné. 


<h2>

Titre

</h2>


<p>

Ciblé

</p>

📌 Sélecteur frère général (~)

Le symbole ~ cible tous les éléments frères après un élément. 


h2 ~ p{

    color:

        white;

}

Tous les paragraphes suivants au même niveau que le h2 seront sélectionnés.

📌 Sélecteurs multiples (,)

Il est possible de sélectionner plusieurs éléments en une seule règle. 


h1, h2, h3{

    font-family:

        Arial;

}

Cette règle applique le même style aux trois titres.

📌 Sélecteur d'attribut

Les sélecteurs d'attribut permettent de cibler des éléments selon leurs attributs HTML. 


input[type="text"]{

    border:

        1px solid white;

}

Ici, seuls les champs ayant : 


type="text"

seront sélectionnés.

📌 Vérifier la présence d'un attribut


a[href]{

    color:

        blue;

}

Tous les liens possédant un attribut href seront sélectionnés.

📌 Attribut contenant une valeur


img[src*="logo"]{

}

Le symbole *= sélectionne les valeurs contenant un texte précis. 


logo.png

↓

✔ sélectionné


image.png

↓

❌ non sélectionné

📌 Attribut commençant par une valeur (^=)


a[href^="https"]{

    color:

        green;

}

Sélectionne les liens qui commencent par https.

📌 Attribut terminant par une valeur ($=)


img[src$=".png"]{

}

Sélectionne les images qui finissent par .png.

📌 Pseudo-classes

Les pseudo-classes permettent de cibler un élément dans un état particulier. 


selector:pseudo-classe{

}

📌 :hover

S'applique lorsque la souris passe au-dessus d'un élément. 


button:hover{

    background:

        blue;

}

Très utilisé pour créer des animations de boutons.

📌 :active

S'applique lorsqu'un élément est en train d'être cliqué. 


button:active{

    transform:

        scale(.9);

}

📌 :focus

S'applique lorsqu'un élément est sélectionné, par exemple un champ texte. 


input:focus{

    border:

        2px solid cyan;

}

📌 :first-child

Sélectionne le premier enfant d'un élément parent. 


li:first-child{

    color:

        red;

}

📌 :last-child


li:last-child{

    color:

        blue;

}

Sélectionne le dernier élément enfant.

📌 :nth-child()

Permet de sélectionner un élément selon sa position. 


li:nth-child(2){

    color:

        yellow;

}

Ici, seul le deuxième élément sera sélectionné. 


1

❌


2

✔


3

❌

📌 :nth-of-type()

La pseudo-classe :nth-of-type() fonctionne comme :nth-child(), mais uniquement avec un type de balise précis. 


p:nth-of-type(2){

    color:

        cyan;

}

Sélectionne le deuxième paragraphe parmi les paragraphes du parent.

📌 :not()

La pseudo-classe :not() permet d'exclure certains éléments. 


p:not(.important){

    color:

        gray;

}

Tous les paragraphes seront sélectionnés sauf ceux possédant la classe important.

📌 :checked

Permet de sélectionner les éléments cochés comme les cases à cocher ou boutons radio. 


input:checked{

    width:

        20px;

}

📌 :disabled

Sélectionne les éléments désactivés. 


button:disabled{

    opacity:

        .5;

}

📌 :valid et :invalid

Ces pseudo-classes permettent de détecter si un champ de formulaire est valide. 


input:valid{

    border:

        2px solid green;

}



input:invalid{

    border:

        2px solid red;

}

📌 Les pseudo-éléments

Les pseudo-éléments permettent de styliser une partie précise d'un élément. 


selector::pseudo-element{

}

📌 ::before

Ajoute du contenu avant un élément. 


.title::before{

    content:

        "★ ";

}

Résultat : 


★ Titre

📌 ::after

Ajoute du contenu après un élément. 


.title::after{

    content:

        " ✓";

}

Résultat : 


Titre ✓

📌 ::first-letter

Permet de modifier la première lettre d'un texte. 


p::first-letter{

    font-size:

        40px;

}

📌 ::first-line


p::first-line{

    font-weight:

        bold;

}

Modifie uniquement la première ligne d'un paragraphe.

📌 ::selection

Permet de modifier l'apparence du texte sélectionné par l'utilisateur. 


::selection{

    background:

        cyan;


    color:

        black;

}

📌 La spécificité CSS

Lorsque plusieurs règles CSS ciblent le même élément, le navigateur utilise la règle ayant la plus grande priorité. 


Priorité :

1. !important


2. id (#)


3. classe (.)


4. balise


5. sélecteur universel (*)

📌 Exemple de spécificité


p{

    color:

        white;

}



.text{

    color:

        blue;

}



#title{

    color:

        red;

}

L'élément ayant l'id title sera rouge car son sélecteur est plus puissant.

📌 !important

!important force une règle à avoir la priorité. 


p{

    color:

        red !important;

}
Il est conseillé d'éviter d'utiliser trop de !important, car cela rend le code difficile à maintenir.

📌 Héritage CSS

Certains styles sont automatiquement transmis aux éléments enfants. 


body{

    color:

        white;

}

Les textes contenus dans la page hériteront de cette couleur.

📌 Propriétés héritées et non héritées


Héritées :

✔ color

✔ font-size

✔ font-family



Non héritées :

❌ margin

❌ padding

❌ border

📌 Erreurs fréquentes

❌ Utiliser trop d'identifiants au lieu des classes.

❌ Créer des sélecteurs trop longs.

❌ Utiliser !important partout.

❌ Oublier l'ordre de priorité CSS.

❌ Modifier un élément alors qu'il faudrait cibler son parent.

⭐ Bonnes pratiques

✔ Utiliser principalement les classes pour organiser le CSS.

✔ Garder des noms de classes simples et compréhensibles.

✔ Éviter les sélecteurs trop spécifiques.

✔ Utiliser les pseudo-classes pour les interactions.

✔ Utiliser les pseudo-éléments pour ajouter des décorations.

✔ Organiser les styles pour éviter les conflits.

📌 Résumé

* sélectionne tous les éléments.

. sélectionne une classe.
# sélectionne un id.
> sélectionne les enfants directs.
+ sélectionne le frère suivant.
~ sélectionne les frères suivants.
[attribut] sélectionne selon un attribut HTML.

:hover, :focus, :active permettent de gérer les interactions.
::before et ::after ajoutent du contenu virtuel.

Les sélecteurs CSS permettent de contrôler précisément l'apparence d'une page web.
