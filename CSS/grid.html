▦ Grid - CSS

CSS Grid est un système de mise en page permettant de créer des grilles complexes avec des lignes et des colonnes. Il est principalement utilisé pour organiser des éléments en deux dimensions.

Contrairement à Flexbox qui fonctionne principalement sur un axe, Grid permet de gérer les lignes et les colonnes en même temps.

📌 Activer Grid


.container{

    display:

        grid;

}

Pour utiliser Grid, il faut appliquer : 


display:grid;

sur l'élément parent qui contiendra les éléments de la grille. 


.container{

    display:

        grid;

}



.item{

}

Ici, .container devient une grille et ses enfants deviennent des éléments de cette grille.

📌 Créer des colonnes

La propriété grid-template-columns permet de définir le nombre et la taille des colonnes. 


.container{

    display:grid;


    grid-template-columns:

        200px 200px;

}

Cet exemple crée deux colonnes de 200 pixels. 


+---------+---------+
|         |         |
| Colonne | Colonne |
|    1    |    2    |
|         |         |
+---------+---------+

📌 Plusieurs colonnes


.container{

    grid-template-columns:

        100px 200px 300px;

}

Chaque valeur correspond à une colonne différente. 


100px

↓

Colonne 1


200px

↓

Colonne 2


300px

↓

Colonne 3

📌 Colonnes égales

Il est possible de créer plusieurs colonnes de même taille. 


.container{

    grid-template-columns:

        1fr 1fr;

}

Le conteneur est divisé en deux parties égales. 


+-------------+-------------+
|             |             |
|      1fr    |     1fr     |
|             |             |
+-------------+-------------+

📌 L'unité fr


.container{

    grid-template-columns:

        1fr 2fr;

}

L'unité fr signifie "fraction". Elle partage l'espace disponible entre les colonnes. 


1fr 1fr


=

50% / 50%



1fr 2fr


=

33% / 66%

📌 repeat()

La fonction repeat() évite de répéter plusieurs fois la même valeur. 


.container{

    grid-template-columns:

        repeat(3, 1fr);

}

Cette écriture crée 3 colonnes identiques.

Équivalent à : 


grid-template-columns:

    1fr 1fr 1fr;

📌 Exemple de grille simple


.container{

    display:grid;


    grid-template-columns:

        repeat(3,1fr);


    gap:

        20px;

}



.card{

    background:

        purple;

}

Cet exemple crée une grille avec 3 cartes par ligne et un espace de 20 pixels entre elles.

📌 Ajouter un espace entre les éléments

La propriété gap ajoute un espace entre les lignes et les colonnes. 


.container{

    display:grid;


    gap:

        20px;

}

Cela évite d'ajouter des marges manuellement sur chaque élément.

📌 Séparer les lignes et colonnes


.container{

    column-gap:

        30px;


    row-gap:

        20px;

}

Deux propriétés permettent de contrôler séparément les espaces : 


column-gap

Espace entre les colonnes



row-gap

Espace entre les lignes

📌 Exemple complet


.grid{

    display:grid;


    grid-template-columns:

        repeat(3,1fr);


    gap:

        25px;

}



.box{

    padding:

        20px;


    background:

        #333;

}

Cette structure est très utilisée pour créer :

✔ Des galeries.
✔ Des cartes produits.
✔ Des tableaux de contenu.

📌 Créer des lignes

Comme pour les colonnes, il est possible de définir la taille des lignes avec grid-template-rows. 


.container{

    display:grid;


    grid-template-rows:

        100px 200px;

}

Cet exemple crée :

✔ Une première ligne de 100 pixels.
✔ Une deuxième ligne de 200 pixels.

📌 Lignes automatiques


.container{

    display:grid;


    grid-template-rows:

        auto;

}

Avec auto, la hauteur de la ligne dépend du contenu présent.

📌 grid-auto-rows

La propriété grid-auto-rows permet de définir la taille des lignes créées automatiquement. 


.container{

    display:grid;


    grid-auto-rows:

        150px;

}

Toutes les nouvelles lignes auront une hauteur de 150 pixels.

📌 Positionner un élément dans une colonne

La propriété grid-column permet de choisir où commence et où termine un élément. 


.item{

    grid-column:

        1 / 3;

}

L'élément occupe les colonnes 1 et 2. 


1       2       3

|-------|-------|

[       ITEM    ]

📌 Étendre un élément sur plusieurs colonnes


.header{

    grid-column:

        span 3;

}

Le mot-clé span permet de définir combien de colonnes l'élément doit occuper. 


grid-column:

    span 2;

L'élément prendra deux colonnes.

📌 Exemple avec plusieurs colonnes


.container{

    display:grid;


    grid-template-columns:

        repeat(3,1fr);

}



.big{

    grid-column:

        span 2;

}

L'élément .big prendra deux colonnes au lieu d'une seule.

📌 Positionner un élément sur une ligne

La propriété grid-row fonctionne comme grid-column, mais pour les lignes. 


.item{

    grid-row:

        1 / 3;

}

L'élément occupe les lignes 1 et 2.

📌 Étendre sur plusieurs lignes


.item{

    grid-row:

        span 2;

}

L'élément prendra deux lignes de hauteur.

📌 Combiner lignes et colonnes


.card{

    grid-column:

        1 / 3;


    grid-row:

        1 / 2;

}

Cela permet de placer précisément un élément dans la grille.

📌 grid-area

La propriété grid-area est une écriture raccourcie permettant de définir : 


grid-row-start

grid-column-start

grid-row-end

grid-column-end




.item{

    grid-area:

        1 / 1 / 3 / 3;

}

L'ordre est : 


ligne début /

colonne début /

ligne fin /

colonne fin

📌 Exemple avec grid-area


.header{

    grid-area:

        1 / 1 / 2 / 4;

}

Le header commence à la ligne 1, colonne 1 et finit à la colonne 4.

📌 La fonction minmax()

La fonction minmax() permet de définir une taille minimale et maximale. 


.container{

    grid-template-columns:

        minmax(200px,500px);

}

La colonne fera :

✔ Minimum : 200 pixels.
✔ Maximum : 500 pixels.

📌 Exemple avec repeat() et minmax()


.container{

    display:grid;


    grid-template-columns:

        repeat(
            3,
            minmax(200px,1fr)
        );

}

Cette technique permet de créer des grilles plus flexibles.

📌 Grille responsive automatique


.container{

    display:grid;


    grid-template-columns:

        repeat(
            auto-fit,
            minmax(250px,1fr)
        );

}

Cette technique adapte automatiquement le nombre de colonnes selon la taille de l'écran.

auto-fit ajoute ou retire des colonnes automatiquement selon l'espace disponible.

📌 auto-fill


.container{

    grid-template-columns:

        repeat(
            auto-fill,
            minmax(200px,1fr)
        );

}

auto-fill crée autant de colonnes que possible même si certaines restent vides.

Différence :

auto-fit : adapte la grille et étire les éléments.
auto-fill : garde les emplacements disponibles.

📌 Exemple de galerie responsive


.gallery{

    display:grid;


    grid-template-columns:

        repeat(
            auto-fit,
            minmax(200px,1fr)
        );


    gap:

        20px;

}

Cette méthode est souvent utilisée pour :

✔ Les galeries photos.
✔ Les cartes produits.
✔ Les menus.

📌 Aligner les éléments dans une grille

CSS Grid permet de contrôler l'alignement des éléments à l'intérieur de leurs cellules.

📌 justify-items

La propriété justify-items contrôle l'alignement horizontal des éléments. 


.container{

    justify-items:

        center;

}



start

À gauche


center

Au centre


end

À droite


stretch

Étire l'élément

Exemple : 


.container{

    display:grid;


    justify-items:

        center;

}

Tous les éléments seront centrés horizontalement dans leur cellule.

📌 align-items

La propriété align-items contrôle l'alignement vertical des éléments. 


.container{

    align-items:

        center;

}



start

En haut


center

Au milieu


end

En bas


stretch

Étire l'élément

📌 place-items

place-items est une propriété raccourcie qui combine : 


align-items

+

justify-items




.container{

    place-items:

        center;

}

Les éléments seront centrés horizontalement et verticalement.

📌 Aligner toute la grille

Les propriétés suivantes déplacent la grille entière dans son conteneur.

📌 justify-content

Contrôle la position horizontale de la grille. 


.container{

    justify-content:

        center;

}



start

À gauche


center

Au centre


end

À droite


space-between

Espace entre les éléments


space-around

Espace autour


space-evenly

Même espace partout

📌 align-content

Contrôle la position verticale de la grille. 


.container{

    align-content:

        center;

}

Les valeurs disponibles sont les mêmes que pour justify-content.

📌 place-content

Combine : 


align-content

+

justify-content




.container{

    place-content:

        center;

}

📌 grid-template-areas

La propriété grid-template-areas permet de créer une mise en page avec des noms de zones. 


.container{

    display:grid;


    grid-template-areas:

        "header header"

        "menu content"

        "footer footer";

}

Chaque mot représente une zone de la grille.

📌 Associer les éléments aux zones


.header{

    grid-area:

        header;

}



.menu{

    grid-area:

        menu;

}



.content{

    grid-area:

        content;

}



.footer{

    grid-area:

        footer;

}

La grille est maintenant organisée automatiquement.

📌 Exemple complet de layout


.container{

    display:grid;


    grid-template-areas:

        "header header"

        "sidebar main"

        "footer footer";


    grid-template-columns:

        200px 1fr;

}



header{

    grid-area:

        header;

}



aside{

    grid-area:

        sidebar;

}



main{

    grid-area:

        main;

}



footer{

    grid-area:

        footer;

}

Cette structure permet de créer un site complet avec :

✔ Un header.
✔ Une barre latérale.
✔ Un contenu principal.
✔ Un footer.

📌 Grille responsive avec media queries

Grid fonctionne très bien avec les media queries pour adapter une page aux écrans mobiles. 


.container{

    display:grid;


    grid-template-columns:

        repeat(3,1fr);

}



@media(max-width:700px){

    .container{

        grid-template-columns:

            1fr;

    }

}

Sur ordinateur : 


[1] [2] [3]

Sur mobile : 


[1]

[2]

[3]

📌 Exemple de cartes responsive


.cards{

    display:grid;


    grid-template-columns:

        repeat(
            auto-fit,
            minmax(250px,1fr)
        );


    gap:

        20px;

}

Cette méthode permet aux cartes de s'adapter automatiquement à la largeur disponible.

📌 Différence entre Grid et Flexbox


Flexbox

=

Une dimension

(ligne OU colonne)



Grid

=

Deux dimensions

(lignes ET colonnes)

Utilisation recommandée : 


Flexbox :

✔ Navigation

✔ Alignement simple

✔ Boutons



Grid :

✔ Layout complet

✔ Galeries

✔ Tableaux

✔ Interfaces complexes

📌 Erreurs fréquentes

❌ Oublier display:grid sur le parent.

❌ Mettre les propriétés Grid sur les mauvais éléments.

❌ Utiliser trop de colonnes fixes qui empêchent le responsive.

❌ Oublier gap et utiliser trop de marges.

❌ Utiliser Grid pour des alignements simples où Flexbox serait plus adapté.

⭐ Bonnes pratiques

✔ Utiliser fr pour créer des grilles flexibles.

✔ Utiliser repeat() pour éviter les répétitions inutiles.

✔ Utiliser minmax() pour créer des designs responsives.

✔ Utiliser grid-template-areas pour les layouts complexes.

✔ Tester la grille sur plusieurs tailles d'écran.

✔ Préférer Grid pour les mises en page en deux dimensions.

📌 Résumé

display:grid active le système Grid.

grid-template-columns crée les colonnes.
grid-template-rows crée les lignes.
gap ajoute des espaces entre les éléments.
grid-column et grid-row placent les éléments.
grid-area permet un placement avancé.
repeat() simplifie la création de grilles.
minmax() rend les grilles plus flexibles.
grid-template-areas permet de créer des layouts complets.

CSS Grid est l'un des outils principaux pour créer des interfaces modernes et responsives.
