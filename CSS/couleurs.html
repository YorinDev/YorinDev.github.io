🎨 Couleurs - CSS

Les couleurs permettent de modifier l'apparence des éléments HTML. Elles peuvent être utilisées pour le texte, les arrière-plans, les bordures ou les effets visuels.

CSS possède plusieurs méthodes pour définir une couleur : nom, HEX, RGB, RGBA, HSL et HSLA.

📌 La propriété color


p{

    color:

        blue;

}

La propriété color modifie la couleur du texte.

📌 La propriété background-color


div{

    background-color:

        red;

}

La propriété background-color change la couleur d'arrière-plan d'un élément.

📌 Couleurs avec un nom


h1{

    color:

        red;

}

CSS possède plus de 140 couleurs prédéfinies avec un nom. 


red

blue

green

black

white

yellow

orange

purple
Les noms sont simples à utiliser mais offrent moins de précision que les autres formats.

📌 Couleurs hexadécimales HEX


div{

    color:

        #00bfff;

}

Le format HEX est l'un des formats les plus utilisés en CSS. 


#RRGGBB

Chaque paire représente une couleur :

RR = Rouge
GG = Vert
BB = Bleu 


#ff0000

Rouge


#00ff00

Vert


#0000ff

Bleu

📌 Version courte HEX


#fff

Lorsque chaque paire possède deux caractères identiques, il est possible de raccourcir la couleur. 


#ffffff

devient

#fff


#000000

devient

#000

📌 Couleurs RGB


div{

    color:

        rgb(
            0,
            200,
            255
        );

}

RGB utilise trois valeurs représentant le rouge, le vert et le bleu. 


rgb(
    rouge,
    vert,
    bleu
)

Chaque valeur est comprise entre 0 et 255.

📌 Couleurs RGBA


div{

    background:

        rgba(
            0,
            200,
            255,
            .5
        );

}

RGBA ajoute une quatrième valeur : l'alpha. 


rgba(
    rouge,
    vert,
    bleu,
    alpha
)

L'alpha contrôle la transparence : 


0

Transparent


0.5

Semi-transparent


1

Visible
RGBA est très utilisé pour créer des interfaces modernes avec des effets de transparence.

📌 Couleurs HSL


div{

    color:

        hsl(
            190,
            100%,
            50%
        );

}

HSL permet de choisir une couleur avec une approche plus naturelle. 


hsl(
    teinte,
    saturation,
    luminosité
)

📌 La teinte (Hue)


0deg

Rouge


120deg

Vert


240deg

Bleu

La teinte correspond à la position de la couleur sur une roue chromatique.

📌 La saturation


100%

Couleur vive


50%

Couleur moins forte


0%

Gris

La saturation contrôle l'intensité de la couleur.

📌 La luminosité


100%

Blanc


50%

Couleur normale


0%

Noir

La luminosité contrôle si la couleur est claire ou sombre.

📌 Couleurs HSLA


div{

    color:

        hsla(
            190,
            100%,
            50%,
            .5
        );

}

HSLA ajoute une transparence au système HSL.

📌 Comparaison des formats


/* Nom */

color:red;



/* HEX */

color:#ff0000;



/* RGB */

color:rgb(255,0,0);



/* RGBA */

color:rgba(255,0,0,.5);



/* HSL */

color:hsl(0,100%,50%);

Toutes ces méthodes peuvent représenter une même couleur.

📌 Variables CSS pour les couleurs


:root{

    --primary:

        #00bfff;

}



button{

    background:

        var(--primary);

}

Les variables CSS permettent de réutiliser facilement les mêmes couleurs dans un projet.

📌 Transparence avec opacity


div{

    opacity:

        .5;

}

La propriété opacity rend tout un élément transparent.

Contrairement à RGBA, opacity affecte aussi le contenu de l'élément.

⭐ Bonnes pratiques

✔ Utiliser une palette de couleurs cohérente.

✔ Utiliser HEX pour les couleurs fixes.

✔ Utiliser RGBA pour les transparences.

✔ Utiliser les variables CSS pour les grandes interfaces.

✔ Vérifier le contraste entre le texte et le fond.

✔ Éviter d'utiliser trop de couleurs différentes.

📌 Résumé

color modifie la couleur du texte.

background-color modifie le fond.
HEX est précis et très utilisé.
RGB utilise rouge, vert et bleu.
RGBA ajoute la transparence.
HSL permet une gestion plus intuitive des couleurs.
HSLA ajoute la transparence au HSL.

Les couleurs sont essentielles pour créer des interfaces modernes et lisibles.
