📦 Padding - CSS

La propriété padding permet d'ajouter un espace intérieur autour du contenu d'un élément. Elle contrôle la distance entre le contenu et la bordure.

Contrairement au margin qui crée un espace extérieur, le padding ajoute de l'espace à l'intérieur de l'élément.

📌 La propriété padding


.element{

    padding:

        20px;

}

Cette règle ajoute 20 pixels d'espace entre le contenu et les bords de l'élément. 


+-----------------------+

|                       |
|      padding          |
|   +-------------+     |
|   |             |     |
|   |  contenu    |     |
|   |             |     |
|   +-------------+     |
|                       |

+-----------------------+

📌 Les quatre côtés

Une seule valeur applique le padding aux quatre côtés. 


.box{

    padding:

        20px;

}

Cela équivaut à : 


.box{

    padding-top:

        20px;


    padding-right:

        20px;


    padding-bottom:

        20px;


    padding-left:

        20px;

}

📌 padding-top

Définit l'espace intérieur en haut de l'élément. 


.box{

    padding-top:

        30px;

}

📌 padding-right

Définit l'espace intérieur à droite. 


.box{

    padding-right:

        25px;

}

📌 padding-bottom

Définit l'espace intérieur en bas. 


.box{

    padding-bottom:

        40px;

}

📌 padding-left

Définit l'espace intérieur à gauche. 


.box{

    padding-left:

        15px;

}

📌 Padding horizontal et vertical

Il est possible de modifier séparément l'espace intérieur horizontal et vertical. 


.box{

    padding:

        20px 40px;

}

La première valeur correspond au haut et bas.
La deuxième valeur correspond à gauche et droite. 


padding:

20px 40px;



=

haut / bas :

20px



gauche / droite :

40px

📌 Padding avec 3 valeurs

Avec trois valeurs, l'ordre devient : 


padding:

10px 20px 30px;

↓

haut



20px

↓

gauche + droite



30px

↓

📌 Padding avec 4 valeurs

Avec quatre valeurs, chaque côté possède sa propre taille. 


.box{

    padding:

        10px 20px 30px 40px;

}



10px

↓

haut


20px

↓

droite


30px

↓

bas


40px

↓

gauche

📌 Propriétés individuelles

Il existe une propriété pour chaque côté. 


padding-top:

20px;



padding-right:

20px;



padding-bottom:

20px;



padding-left:

20px;
Ces propriétés permettent de modifier un seul côté sans toucher aux autres.

📌 Exemple avec un bouton


button{

    padding:

        15px 30px;


    background:

        purple;


    color:

        white;

}

Le padding augmente la taille du bouton en ajoutant de l'espace autour du texte.

📌 Padding et taille d'un élément

Par défaut, le padding augmente la taille totale d'un élément. 


.box{

    width:

        200px;


    padding:

        20px;

}

La largeur totale devient : 


200px

+

20px gauche

+

20px droite


=

240px

📌 box-sizing: border-box

La propriété box-sizing permet de garder la taille définie malgré le padding. 


.box{

    width:

        200px;


    padding:

        20px;


    box-sizing:

        border-box;

}

Avec border-box, le padding est inclus dans la largeur totale. 


Largeur totale :

200px


Contenu :

160px


Padding :

40px

📌 Padding dans une carte


.card{

    width:

        300px;


    padding:

        25px;


    background:

        #222;


    border-radius:

        15px;

}

Le padding crée un espace entre le contenu et les bords de la carte.

📌 Différence entre margin et padding


Margin

=

📌 Padding avec les éléments inline

Les éléments inline peuvent utiliser le padding, mais son comportement est différent. 


span{

    padding:

        20px;

}

Le padding horizontal fonctionne normalement.

Cependant, le padding vertical peut ne pas déplacer les autres éléments autour.

Pour contrôler correctement le padding vertical, il est souvent préférable d'utiliser :

display:inline-block; 

span{

    display:

        inline-block;


    padding:

        20px;

}

📌 Padding et images

Le padding peut être utilisé autour des images pour créer un espace intérieur. 


img{

    padding:

        10px;


    border:

        2px solid white;

}

Résultat : 


+----------------+

|   padding      |

|  +--------+    |

|  | image  |    |

|  +--------+    |

|                |

+----------------+

📌 Padding dans une navigation

Le padding est souvent utilisé pour créer des liens plus faciles à cliquer. 


nav a{

    padding:

        15px 25px;


    text-decoration:

        none;

}

Le lien devient plus grand sans modifier la taille du texte.

📌 Padding avec des variables CSS

Les variables CSS permettent de réutiliser des valeurs de padding. 


:root{

    --spacing:

        20px;

}



.box{

    padding:

        var(--spacing);

}

Si la valeur change, tous les éléments utilisant cette variable sont modifiés.

📌 Padding responsive

Le padding peut être adapté selon la taille de l'écran avec les media queries. 


.box{

    padding:

        40px;

}



@media(max-width:700px){

    .box{

        padding:

            20px;

    }

}

Sur ordinateur, l'espace intérieur est plus grand.
Sur mobile, il est réduit pour garder plus de place.

📌 Padding avec des unités différentes

Le padding peut utiliser plusieurs unités CSS. 


.box{

    padding:

        5%;


}



.box{

    padding:

        2rem;

}


.box{

    padding:

        20px;

}




px

=

Valeur fixe



%

=

Pourcentage du parent



rem

=

Taille relative au texte principal

📌 Padding et design moderne

Le padding est très utilisé dans les interfaces modernes pour créer de l'espace et améliorer la lisibilité. 


.card{

    padding:

        30px;


    border-radius:

        20px;


    background:

        rgba(255,255,255,.05);

}

Cette technique est utilisée pour créer :

✔ Des cartes.
✔ Des fenêtres.
✔ Des boutons modernes.
✔ Des menus.

📌 Erreurs fréquentes

❌ Utiliser trop peu de padding et avoir un contenu collé aux bords.

❌ Confondre padding et margin.

❌ Ajouter du padding sans penser à box-sizing.

❌ Utiliser des valeurs différentes partout au lieu de variables.

❌ Mettre de grandes valeurs de padding sur mobile.

⭐ Bonnes pratiques

✔ Utiliser box-sizing:border-box pour mieux contrôler les tailles.

✔ Utiliser des valeurs cohérentes dans tout le site.

✔ Utiliser padding pour l'espace intérieur.

✔ Préférer les raccourcis lorsque les valeurs sont identiques.

✔ Adapter le padding avec des media queries pour le responsive.

✔ Garder suffisamment d'espace autour du contenu.

📌 Résumé

padding ajoute de l'espace à l'intérieur d'un élément.

padding-top contrôle le haut.
padding-right contrôle la droite.
padding-bottom contrôle le bas.
padding-left contrôle la gauche.

padding: 10px 20px; permet de définir plusieurs côtés rapidement.

box-sizing:border-box; permet de garder une taille maîtrisée.

Le padding est essentiel pour créer des interfaces propres et lisibles.
