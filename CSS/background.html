🎨 Background - CSS

La propriété background permet de modifier l'arrière-plan d'un élément. On peut utiliser une couleur, une image ou même un dégradé.

📌 Couleur de fond


body{

    background: lightblue;

}
La propriété background peut recevoir directement une couleur.

📌 background-color


body{

    background-color: #00bfff;

}

Cette propriété modifie uniquement la couleur de fond.

📌 Image de fond


body{

    background-image: url("image.jpg");

}

Permet d'utiliser une image comme arrière-plan.

📌 Ne pas répéter l'image


body{

    background-repeat: no-repeat;

}

Empêche l'image de se répéter plusieurs fois.

📌 Couvrir tout l'écran


body{

    background-size: cover;

}

L'image est agrandie afin de couvrir toute la surface.

📌 Centrer l'image


body{

    background-position: center;

}

Place l'image au centre de l'élément.

📌 Image fixe


body{

    background-attachment: fixed;

}

L'image reste fixe lorsque la page défile.

📌 Dégradé


body{

    background: linear-gradient(
        to right,
        #00bfff,
        #0044ff
    );

}

Crée un dégradé entre plusieurs couleurs.

📌 Dégradé radial


body{

    background: radial-gradient(
        circle,
        #00bfff,
        #001133
    );

}

Le dégradé part du centre vers l'extérieur.

📌 Écriture raccourcie


body{

    background:
        url("fond.jpg")
        center
        / cover
        no-repeat;

}

La propriété background permet de définir plusieurs paramètres en une seule ligne.

⭐ Bonnes pratiques

✔ Utiliser background-size: cover; pour les images plein écran.

✔ Ajouter background-repeat: no-repeat; pour éviter les répétitions.

✔ Préférer les dégradés CSS plutôt que des images lorsque c'est possible.

✔ Compresser les images de fond pour accélérer le chargement.

✔ Choisir un fond qui garde le texte facilement lisible.
