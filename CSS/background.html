🎨 Background - CSS

La propriété background permet de modifier l'arrière-plan d'un élément HTML. Elle peut être utilisée pour ajouter une couleur, une image, un dégradé ou plusieurs arrière-plans. 


element{

    background: valeur;

}
La propriété background est une propriété raccourcie. Elle permet de modifier plusieurs propriétés liées au fond en une seule ligne.

📌 La propriété background


div{

    background: blue;

}

Dans cet exemple, l'arrière-plan du div devient bleu. 


div{

    background:

        #00bfff;

}

Il est possible d'utiliser une couleur, une image ou un dégradé directement avec background.

📌 background-color


body{

    background-color:

        black;

}

La propriété background-color permet uniquement de modifier la couleur d'arrière-plan d'un élément.

Contrairement à background, cette propriété ne permet pas d'ajouter d'image ou de dégradé.

📌 Appliquer une couleur à un élément


.card{

    background-color:

        #00bfff;

}

Ici, l'élément avec la classe card aura un fond bleu clair.

📌 Couleur transparente


div{

    background-color:

        transparent;

}

La valeur transparent rend l'arrière-plan complètement invisible. 


.box{

    background-color:

        transparent;

    border:

        1px solid white;

}

Cela permet par exemple de créer des éléments avec uniquement une bordure visible.

📌 Hériter la couleur du parent


div{

    background-color:

        inherit;

}

La valeur inherit récupère la couleur d'arrière-plan de l'élément parent. 


.parent{

    background-color:

        blue;

}



.child{

    background-color:

        inherit;

}

Dans cet exemple, l'élément enfant aura également un fond bleu.

📌 Exemple complet


body{

    background-color:

        #020810;

    color:

        white;

}



.card{

    background-color:

        rgba(0,200,255,.1);

    padding:

        20px;

    border-radius:

        15px;

}

Cet exemple est souvent utilisé pour créer des cartes modernes avec un fond légèrement transparent.

⭐ Bonnes pratiques

✔ Utiliser background-color lorsque seule une couleur est nécessaire.

✔ Préférer les couleurs avec contraste pour garder un texte lisible.

✔ Utiliser rgba() pour créer des fonds transparents modernes.

✔ Éviter les couleurs trop vives derrière du texte.

✔ Tester l'affichage sur plusieurs écrans.

📌 Résumé

background permet de modifier complètement l'arrière-plan d'un élément.

background-color sert uniquement à changer la couleur du fond.

Ces propriétés sont utilisées dans presque tous les sites web pour créer des interfaces visuelles.

📌 Les couleurs CSS

CSS propose plusieurs façons de définir une couleur. Les principales méthodes sont :

✔ Nom de couleur
✔ Code hexadécimal
✔ RGB
✔ RGBA
✔ HSL
✔ HSLA

📌 Couleurs avec un nom


div{

    background-color:

        red;

}

CSS possède plusieurs couleurs prédéfinies avec un nom. 


red

blue

green

black

white

yellow

orange

purple

Exemple : 


h1{

    color:

        blue;

}

Le texte du titre deviendra bleu.

Il existe plus de 140 noms de couleurs disponibles en CSS. Cependant, les noms sont limités et offrent moins de précision que les autres méthodes.

📌 Couleurs hexadécimales


div{

    background-color:

        #00bfff;

}

Le format hexadécimal est l'une des méthodes les plus utilisées en CSS. 


#RRGGBB

Une couleur hexadécimale contient 6 caractères :

RR représente le rouge.
GG représente le vert.
BB représente le bleu. 


#ff0000

Rouge


#00ff00

Vert


#0000ff

Bleu

📌 Version courte hexadécimale


#fff

Lorsque chaque paire possède deux caractères identiques, il est possible de raccourcir l'écriture. 


#ffffff

devient

#fff


#000000

devient

#000
Les deux écritures donnent exactement le même résultat.

📌 Couleurs RGB


div{

    background-color:

        rgb(0,200,255);

}

La fonction rgb() permet de définir une couleur avec les valeurs rouge, vert et bleu. 


rgb(
    rouge,
    vert,
    bleu
)

Chaque valeur est comprise entre : 


0

et

255



rgb(255,0,0)

Rouge


rgb(0,255,0)

Vert


rgb(0,0,255)

Bleu

📌 Couleurs RGBA


div{

    background-color:

        rgba(0,200,255,.5);

}

La fonction rgba() est une version de RGB avec une valeur supplémentaire : 


rgba(
    rouge,
    vert,
    bleu,
    alpha
)

La valeur alpha correspond à la transparence. 


0

Complètement transparent


0.5

Semi-transparent


1

Complètement visible

Exemple : 


.card{

    background:

        rgba(0,200,255,.2);

}

Le fond sera bleu mais légèrement transparent.

RGBA est très utilisé pour créer des interfaces modernes avec des effets de verre, des cartes transparentes ou des overlays.

📌 Couleurs HSL


div{

    background-color:

        hsl(190,100%,50%);

}

La fonction hsl() utilise une approche plus naturelle pour choisir une couleur. 


hsl(
    teinte,
    saturation,
    luminosité
)

📌 La teinte (Hue)


0deg

Rouge


120deg

Vert


240deg

Bleu

La teinte correspond à la position de la couleur sur une roue chromatique.

📌 La saturation


100%

Couleur très vive


50%

Couleur moins intense


0%

Gris

La saturation contrôle l'intensité de la couleur.

📌 La luminosité


100%

Blanc


50%

Couleur normale


0%

Noir

La luminosité contrôle si la couleur est claire ou sombre.

📌 Couleurs HSLA


div{

    background-color:

        hsla(
            190,
            100%,
            50%,
            .5
        );

}

Comme RGBA, HSLA ajoute une valeur de transparence. 


hsla(
    teinte,
    saturation,
    luminosité,
    alpha
)

📌 Comparaison des méthodes


/* Nom */

color:red;



/* Hex */

color:#ff0000;



/* RGB */

color:rgb(255,0,0);



/* RGBA */

color:rgba(255,0,0,.5);



/* HSL */

color:hsl(0,100%,50%);

Toutes ces écritures peuvent représenter la même couleur.

📌 Exemple complet


.card{

    background-color:

        rgba(
            0,
            200,
            255,
            .15
        );



    border:

        1px solid #00bfff;



    color:

        hsl(
            0,
            0%,
            100%
        );

}

Cet exemple mélange plusieurs formats de couleurs utilisés dans les designs modernes.

⭐ Bonnes pratiques

✔ Utiliser HEX ou RGB pour les couleurs fixes.

✔ Utiliser RGBA ou HSLA pour ajouter de la transparence.

✔ Préférer HSL lorsque l'on veut facilement modifier la luminosité d'une couleur.

✔ Garder une palette de couleurs cohérente dans un site.

✔ Vérifier le contraste entre le texte et l'arrière-plan.

📌 Résumé

CSS permet de définir des couleurs avec plusieurs systèmes :

Nom : simple mais limité.
HEX : précis et très utilisé.
RGB : basé sur les couleurs rouge, vert et bleu.
RGBA : ajoute la transparence.
HSL : plus intuitif pour modifier une couleur.
HSLA : ajoute la transparence au HSL.

📌 background-image

La propriété background-image permet d'ajouter une image en arrière-plan d'un élément. 


div{

    background-image:

        url("image.png");

}
Une image de fond ne remplace pas le contenu d'un élément. Elle est placée derrière le texte et les autres éléments présents.

📌 Utiliser une image locale


body{

    background-image:

        url("images/fond.png");

}

Une image locale correspond à une image présente dans votre projet.

Exemple de rangement : 


Site/

│

├── index.html

│

├── css/

│   └── style.css

│

└── images/

    └── fond.png

Pour accéder au dossier images depuis un fichier CSS : 


body{

    background-image:

        url("../images/fond.png");

}
Dans un fichier CSS, le chemin est calculé depuis l'emplacement du fichier CSS et non depuis la page HTML.

📌 Utiliser une image externe


body{

    background-image:

        url(
        "https://site.com/image.png"
        );

}

Il est également possible d'utiliser une image située sur un autre serveur.

Une image externe dépend du serveur qui l'héberge. Si l'image est supprimée ou déplacée, elle ne fonctionnera plus.

📌 Aucune image


div{

    background-image:

        none;

}

La valeur none supprime l'image d'arrière-plan.

📌 Ajouter une image avec background


div{

    background:

        url("fond.png");

}

La propriété raccourcie background peut également ajouter une image. 


div{

    background:

        blue

        url("fond.png");

}

Dans cet exemple :

✔ Le fond est bleu.
✔ L'image est affichée par-dessus.

📌 Plusieurs images de fond


div{

    background-image:

        url("nuage.png"),

        url("ciel.png");

}

CSS permet d'utiliser plusieurs images en même temps.

La première image écrite est placée au-dessus des autres. 

background-image:

    url("avant.png"),

    url("arriere.png");

Dans cet exemple :

avant.png sera devant.
arriere.png sera derrière.

📌 Exemple avec plusieurs images


body{

    background-image:

        url("logo.png"),

        url("background.jpg");

}

Le logo sera affiché au-dessus de l'image de fond.

📌 Ajouter une couleur derrière une image


div{

    background:

        #001122

        url("fond.png");

}

La couleur sert de fond de secours si l'image ne charge pas.

Il est recommandé d'ajouter une couleur avec une image pour éviter un fond vide en cas de problème de chargement.

📌 Image avec transparence


div{

    background-image:

        url("overlay.png");

}

Les images PNG avec transparence sont souvent utilisées pour ajouter des effets par-dessus un fond.

Exemples d'utilisation :

✔ Particules.
✔ Motifs.
✔ Logos.
✔ Effets lumineux.

📌 Superposer une couleur et une image


div{

    background:

        linear-gradient(

            rgba(0,0,0,.5),

            rgba(0,0,0,.5)

        ),

        url("image.jpg");

}

Cette technique ajoute une couche sombre au-dessus de l'image.

Très utilisée pour rendre un texte lisible sur une image.

📌 Exemple de bannière


.banner{

    background:

        linear-gradient(

            rgba(0,0,0,.4),

            rgba(0,0,0,.4)

        ),

        url("banner.jpg");


    height:

        300px;

}

Cette technique est souvent utilisée pour créer :

✔ Des pages d'accueil.
✔ Des bannières.
✔ Des sections de présentation.

📌 Image et taille automatique


div{

    background-image:

        url("image.png");

}

Par défaut, l'image garde sa taille originale.

La propriété background-size permet ensuite de contrôler la taille de l'image. Elle sera expliquée dans une prochaine partie.

⭐ Bonnes pratiques

✔ Utiliser des images optimisées pour éviter de ralentir le site.

✔ Prévoir une couleur de secours derrière chaque image.

✔ Utiliser des formats adaptés comme PNG, JPG ou WebP.

✔ Éviter les images trop grandes inutilement.

✔ Utiliser des images libres de droits ou dont vous possédez l'autorisation.

📌 Résumé

background-image permet d'ajouter une image derrière un élément.

La fonction url() indique l'emplacement de l'image.

Il est possible d'utiliser plusieurs images et de les superposer.

Les images de fond sont très utilisées pour les bannières, les cartes et les interfaces modernes.

📌 background-repeat

La propriété background-repeat contrôle la manière dont une image de fond se répète dans un élément. 


div{

    background-repeat:

        valeur;

}

Par défaut, une image de fond se répète horizontalement et verticalement. 


div{

    background-image:

        url("pattern.png");


    background-repeat:

        repeat;

}

📌 repeat


div{

    background-repeat:

        repeat;

}

La valeur repeat est la valeur par défaut.

L'image est répétée dans toutes les directions :

✔ Horizontalement.
✔ Verticalement. 


+---+---+---+

|img|img|img|

+---+---+---+

|img|img|img|

+---+---+---+

📌 no-repeat


div{

    background-repeat:

        no-repeat;

}

La valeur no-repeat empêche toute répétition de l'image. 


.card{

    background-image:

        url("logo.png");


    background-repeat:

        no-repeat;

}

Très utilisé pour afficher un logo ou une image unique.

📌 repeat-x


div{

    background-repeat:

        repeat-x;

}

L'image est répétée uniquement horizontalement. 


+---+---+---+

|img|img|img|

+---+---+---+

Exemple d'utilisation :

✔ Motifs horizontaux.
✔ Lignes décoratives.
✔ Barres de fond.

📌 repeat-y


div{

    background-repeat:

        repeat-y;

}

L'image est répétée uniquement verticalement. 


+---+

|img|

+---+

|img|

+---+

|img|

+---+

Exemple :

✔ Bordures décoratives verticales.
✔ Motifs sur les côtés.

📌 space


div{

    background-repeat:

        space;

}

La valeur space répète l'image en ajoutant un espace identique entre chaque répétition.

Contrairement à repeat, l'image n'est jamais coupée. Le navigateur ajoute automatiquement des espaces pour que les images rentrent parfaitement.

📌 round


div{

    background-repeat:

        round;

}

La valeur round redimensionne les images afin qu'elles remplissent parfaitement l'espace disponible.

Avec round, l'image peut être légèrement agrandie ou réduite.

📌 Contrôler horizontalement et verticalement


div{

    background-repeat:

        no-repeat repeat;

}

Il est possible de définir deux valeurs :

Première valeur : répétition horizontale.
Deuxième valeur : répétition verticale. 


background-repeat:

    repeat no-repeat;

L'image se répète horizontalement mais pas verticalement.

📌 Exemple complet avec repeat


body{

    background-image:

        url("pattern.png");


    background-repeat:

        repeat;

}

Cette technique est souvent utilisée pour créer des motifs répétitifs.

📌 background-position

La propriété background-position permet de choisir l'emplacement d'une image de fond. 


div{

    background-position:

        position;

}
Par défaut, l'image commence en haut à gauche de l'élément.

📌 center


div{

    background-position:

        center;

}

Place l'image au centre de l'élément. 


+-----------+

|           |

|    IMG    |

|           |

+-----------+

📌 top


div{

    background-position:

        top;

}

Place l'image en haut de l'élément.

📌 bottom


div{

    background-position:

        bottom;

}

Place l'image en bas de l'élément.

📌 left


div{

    background-position:

        left;

}

Place l'image à gauche.

📌 right


div{

    background-position:

        right;

}

Place l'image à droite.

📌 Combiner plusieurs positions


div{

    background-position:

        center top;

}

Il est possible de combiner deux valeurs. 


left top


right top


center center


left bottom


right bottom

Exemples :

center top place l'image au centre horizontalement et en haut.

right bottom place l'image en bas à droite.

📌 Position avec des pourcentages


div{

    background-position:

        50% 50%;

}

Les pourcentages permettent de placer l'image précisément. 


50% 50%

Centre


0% 0%

Coin supérieur gauche


100% 100%

Coin inférieur droit

📌 Position avec des pixels


div{

    background-position:

        20px 50px;

}

La première valeur correspond au déplacement horizontal.

La deuxième valeur correspond au déplacement vertical. 


background-position:

    100px 30px;

L'image sera déplacée de 100 pixels vers la droite et 30 pixels vers le bas.

📌 Exemple complet


.banner{

    height:

        300px;


    background-image:

        url("image.jpg");


    background-repeat:

        no-repeat;


    background-position:

        center;

}

Cet exemple crée une bannière avec une image unique centrée.

⭐ Bonnes pratiques

✔ Utiliser no-repeat pour les images qui ne doivent apparaître qu'une seule fois.

✔ Utiliser center pour centrer rapidement une image.

✔ Utiliser les pourcentages lorsque vous avez besoin d'un placement précis.

✔ Éviter les répétitions involontaires qui peuvent rendre un design illisible.

✔ Tester le résultat sur plusieurs tailles d'écran.

📌 Résumé

background-repeat contrôle la répétition d'une image.

background-position contrôle son emplacement.

Ces deux propriétés sont souvent utilisées ensemble avec background-image pour créer des arrière-plans adaptés.

📌 background-size

La propriété background-size permet de modifier la taille d'une image d'arrière-plan. 


div{

    background-size:

        valeur;

}
Par défaut, une image de fond garde sa taille originale.

📌 Valeur auto


div{

    background-size:

        auto;

}

La valeur auto conserve la taille originale de l'image. 


.banner{

    background-image:

        url("image.png");


    background-size:

        auto;

}

L'image ne sera ni agrandie ni réduite.

📌 Taille en pixels


div{

    background-size:

        300px;

}

Il est possible de définir une largeur précise. 


div{

    background-size:

        300px 200px;

}

La première valeur correspond à la largeur.

La deuxième valeur correspond à la hauteur.

Modifier les dimensions peut déformer l'image si le ratio n'est pas respecté.

📌 Taille en pourcentage


div{

    background-size:

        50%;

}

Le pourcentage est calculé par rapport à la taille de l'élément. 


div{

    background-size:

        100% 100%;

}

L'image prendra toute la largeur et toute la hauteur du conteneur.

📌 cover


div{

    background-size:

        cover;

}

La valeur cover agrandit ou réduit l'image afin qu'elle remplisse entièrement l'élément.

Avec cover, l'image peut être coupée si son ratio est différent de celui du conteneur. 

.banner{

    width:

        100%;


    height:

        400px;


    background-image:

        url("background.jpg");


    background-size:

        cover;

}

Très utilisé pour :

✔ Les bannières.
✔ Les images d'accueil.
✔ Les sections plein écran.

📌 contain


div{

    background-size:

        contain;

}

La valeur contain

Contrairement à cover, l'image ne sera jamais coupée. Cependant, il peut rester de l'espace vide. 

.logo{

    background-image:

        url("logo.png");


    background-size:

        contain;


    background-repeat:

        no-repeat;

}

Très utile pour :

✔ Les logos.
✔ Les icônes.
✔ Les images qui doivent rester entièrement visibles.

📌 Différence entre cover et contain


cover

Image complète du bloc remplie

+

Image parfois coupée



contain

Image complète visible

+

Espace vide possible

Exemple :

Une image carrée dans une bannière rectangulaire :

cover : l'image remplit la bannière mais une partie disparaît.
contain : toute l'image apparaît mais des espaces restent.

📌 Exemple complet avec cover


.hero{

    height:

        500px;


    background-image:

        url("forest.jpg");


    background-size:

        cover;


    background-position:

        center;

}

Cette configuration est très courante pour les grandes sections d'accueil.

📌 background-attachment

La propriété background-attachment définit comment l'image réagit au défilement de la page. 


body{

    background-attachment:

        valeur;

}

📌 scroll


body{

    background-attachment:

        scroll;

}

Valeur par défaut. L'image défile normalement avec la page.

📌 fixed


body{

    background-attachment:

        fixed;

}

L'image reste fixe pendant que le contenu défile.

Cette technique est souvent utilisée pour créer des effets de parallaxe. 

body{

    background-image:

        url("space.jpg");


    background-attachment:

        fixed;


    background-size:

        cover;

}

📌 local


div{

    background-attachment:

        local;

}

Avec local, l'image suit le défilement du contenu de l'élément lui-même.

Cette valeur est principalement utilisée avec des éléments possédant leur propre scroll.

📌 background-origin

La propriété background-origin définit la zone utilisée comme référence pour positionner l'image. 


div{

    background-origin:

        valeur;

}

📌 border-box


div{

    background-origin:

        border-box;

}

L'image commence depuis la bordure de l'élément.

📌 padding-box


div{

    background-origin:

        padding-box;

}

Valeur par défaut. L'image commence depuis la zone de padding.

📌 content-box


div{

    background-origin:

        content-box;

}

L'image est positionnée uniquement dans la zone du contenu.

📌 background-clip

La propriété background-clip définit jusqu'où l'arrière-plan est affiché. 


div{

    background-clip:

        valeur;

}

📌 border-box


div{

    background-clip:

        border-box;

}

Le fond est affiché sous la bordure.

📌 padding-box


div{

    background-clip:

        padding-box;

}

Le fond s'arrête avant la bordure.

📌 content-box


div{

    background-clip:

        content-box;

}

Le fond est affiché uniquement derrière le contenu.

📌 background-clip: text


h1{

    background:

        linear-gradient(
            red,
            blue
        );


    background-clip:

        text;


    color:

        transparent;

}

Cette technique permet de remplir un texte avec une image ou un dégradé.

Cette propriété est souvent utilisée pour créer des titres avec des effets modernes.

⭐ Bonnes pratiques

✔ Utiliser cover pour les grandes images de fond.

✔ Utiliser contain lorsque l'image entière doit être visible.

✔ Utiliser fixed avec modération car il peut être lourd sur certains appareils.

✔ Préférer des images optimisées pour les grands arrière-plans.

✔ Tester les fonds sur mobile.

📌 Résumé

background-size contrôle la taille de l'image.

cover remplit complètement un élément.

contain garde toute l'image visible.

background-attachment contrôle le comportement lors du défilement.

background-origin et background-clip contrôlent la zone d'affichage du fond.

📌 Les dégradés CSS

Les dégradés permettent de créer des transitions entre plusieurs couleurs sans utiliser d'image.

Les dégradés sont considérés comme des images par CSS. Ils peuvent donc être utilisés avec background-image.

📌 linear-gradient()

La fonction linear-gradient() crée un dégradé en ligne droite. 


div{

    background:

        linear-gradient(
            red,
            blue
        );

}

Cet exemple crée une transition du rouge vers le bleu.

📌 Dégradé vertical


div{

    background:

        linear-gradient(
            red,
            blue
        );

}

Par défaut, le dégradé va du haut vers le bas.

📌 Dégradé horizontal


div{

    background:

        linear-gradient(
            to right,
            red,
            blue
        );

}

Le mot-clé to right indique que le dégradé va vers la droite.

📌 Les directions possibles


to top

Vers le haut


to bottom

Vers le bas


to left

Vers la gauche


to right

📌 Plusieurs couleurs


div{

    background:

        linear-gradient(
            red,
            yellow,
            blue
        );

}

Un dégradé peut contenir autant de couleurs que nécessaire.

📌 Positionner les couleurs


div{

    background:

        linear-gradient(
            red 20%,
            blue 80%
        );

}

Les pourcentages permettent de contrôler où commence chaque couleur.

📌 Dégradé avec transparence


div{

    background:

        linear-gradient(
            rgba(0,0,0,.8),
            transparent
        );

}

Très utilisé pour ajouter une couche sombre sur une image.

📌 Exemple : image avec overlay sombre


.hero{

    background-image:

        linear-gradient(
            rgba(0,0,0,.6),
            rgba(0,0,0,.6)
        ),

        url("image.jpg");


    background-size:

        cover;

}

Cet effet permet de rendre du texte lisible sur une image.

📌 radial-gradient()

La fonction radial-gradient() crée un dégradé circulaire. 


div{

    background:

        radial-gradient(
            red,
            blue
        );

}

La première couleur commence au centre et se diffuse vers l'extérieur.

📌 Cercle ou ellipse


radial-gradient(

    circle,

    red,

    blue

)


radial-gradient(

    ellipse,

    red,

    blue

)

circle crée un cercle parfait.

ellipse adapte le dégradé à la taille de l'élément.

📌 Plusieurs arrière-plans

CSS permet d'utiliser plusieurs images de fond en même temps. 


div{

    background-image:

        url("logo.png"),

        url("background.jpg");

}

La première image écrite est affichée au-dessus des suivantes.

📌 Exemple avec plusieurs fonds


body{

    background-image:

        url("stars.png"),

        linear-gradient(
            black,
            blue
        );

}

Dans cet exemple :

✔ Les étoiles sont au premier plan.
✔ Le dégradé sert de fond.

📌 La propriété raccourcie background

La propriété background permet de regrouper plusieurs propriétés en une seule ligne. 


div{

    background:

        couleur

        image

        position

        taille

        répétition;

}

📌 Exemple simple


div{

    background:

        red

        url("image.png")

        center

        no-repeat;

}

Cette ligne remplace plusieurs propriétés : 


background-color:

    red;


background-image:

    url("image.png");


background-position:

    center;


background-repeat:

    no-repeat;

📌 Exemple complet moderne


.card{

    width:

        400px;


    height:

        250px;


    background:

        linear-gradient(
            rgba(0,0,0,.5),
            rgba(0,0,0,.5)
        ),

        url("forest.jpg")

        center

        / cover

        no-repeat;

}

Cette syntaxe est souvent utilisée pour les cartes, bannières et sections d'accueil.

📌 Erreurs fréquentes

❌ Oublier background-size: cover pour une grande image.

❌ Utiliser une image trop lourde.

❌ Mettre une image sans contraste derrière du texte.

❌ Utiliser trop de dégradés complexes.

❌ Oublier no-repeat lorsque l'image ne doit pas se répéter.

⭐ Bonnes pratiques

✔ Optimiser la taille des images avant de les utiliser.

✔ Utiliser cover pour les grandes zones.

✔ Utiliser contain pour les logos et icônes.

✔ Ajouter un overlay avec un dégradé pour améliorer la lisibilité.

✔ Préférer les formats modernes comme WebP lorsque possible.

✔ Tester les arrière-plans sur ordinateur et mobile.

📌 Résumé complet

La propriété background permet de gérer tous les arrière-plans CSS.

background-color ajoute une couleur.
background-image ajoute une image ou un dégradé.
background-repeat contrôle la répétition.
background-position contrôle la position.
background-size contrôle la taille.
background-attachment contrôle le défilement.
background-origin et background-clip contrôlent les zones d'affichage.

Avec ces propriétés, il est possible de créer des interfaces modernes, des bannières, des cartes et des effets visuels avancés uniquement avec CSS.
