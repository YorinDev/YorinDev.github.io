📦 Flexbox - CSS

Flexbox est un système de mise en page CSS permettant d'organiser facilement des éléments dans un conteneur. Il est particulièrement utilisé pour créer des interfaces responsives.

Flexbox fonctionne avec un élément parent appelé flex container et des éléments enfants appelés flex items.

📌 Activer Flexbox


.container{

    display:

        flex;

}

La propriété display:flex transforme un élément en conteneur Flexbox.

📌 L'axe principal

Flexbox organise les éléments selon deux axes : 


Axe principal

↓

Direction des éléments


Axe secondaire

↓

Alignement des éléments
Par défaut, l'axe principal est horizontal.

📌 flex-direction


.container{

    flex-direction:

        row;

}

Cette propriété définit la direction des éléments. 


row

Gauche vers droite


row-reverse

Droite vers gauche


column

Haut vers bas


column-reverse

Bas vers haut

📌 Exemple en colonne


.container{

    display:flex;


    flex-direction:

        column;

}

Les éléments seront placés verticalement.

📌 justify-content


.container{

    justify-content:

        center;

}

Cette propriété contrôle l'alignement sur l'axe principal. 


flex-start

Au début


center

Au centre


flex-end

A la fin


space-between

Espace entre les éléments


space-around

Espace autour


space-evenly

Espace égal

📌 align-items


.container{

    align-items:

        center;

}

Cette propriété aligne les éléments sur l'axe secondaire. 


stretch

Étire les éléments


flex-start

Au début


center

Au centre


flex-end

A la fin

📌 gap


.container{

    gap:

        20px;

}

La propriété gap ajoute un espace entre les éléments.

Contrairement à margin, gap ne crée pas d'espace autour du conteneur.

📌 flex-wrap


.container{

    flex-wrap:

        wrap;

}

Permet aux éléments de passer à la ligne lorsque l'espace manque. 


nowrap

Une seule ligne


wrap

Retour à la ligne


wrap-reverse

Retour inversé

📌 Exemple responsive


.cards{

    display:flex;


    flex-wrap:

        wrap;


    gap:

        20px;

}

Très utilisé pour créer des grilles adaptatives.

📌 align-content


.container{

    align-content:

        center;

}

Contrôle l'espace entre plusieurs lignes Flexbox.

Cette propriété fonctionne uniquement lorsque plusieurs lignes existent avec flex-wrap.

📌 Modifier un élément enfant

📌 order


.item{

    order:

        2;

}

Change l'ordre d'affichage d'un élément.

📌 flex-grow


.item{

    flex-grow:

        1;

}

Permet à un élément de prendre l'espace disponible.

📌 flex-shrink


.item{

    flex-shrink:

        1;

}

Définit comment un élément réduit sa taille lorsque l'espace manque.

📌 flex-basis


.item{

    flex-basis:

        200px;

}

Définit la taille de départ d'un élément Flexbox.

📌 La propriété flex


.item{

    flex:

        1;

}

La propriété flex est un raccourci pour : 


flex-grow

flex-shrink

flex-basis




.item{

    flex:

        1 1 200px;

}

📌 Exemple complet


.container{

    display:flex;


    justify-content:

        center;


    align-items:

        center;


    gap:

        20px;


    flex-wrap:

        wrap;

}



.card{

    flex:

        1 1 250px;

}

Cette configuration est souvent utilisée pour créer des cartes responsives.

📌 Centrer un élément parfaitement


.container{

    display:flex;


    justify-content:

        center;


    align-items:

        center;

}

C'est l'une des utilisations les plus populaires de Flexbox.

⭐ Bonnes pratiques

✔ Utiliser Flexbox pour aligner rapidement des éléments.

✔ Préférer gap plutôt que plusieurs marges.

✔ Utiliser flex-wrap pour les designs responsives.

✔ Éviter de mélanger trop de techniques de positionnement.

✔ Utiliser flex:1 pour répartir facilement l'espace.

📌 Résumé

display:flex active Flexbox.

flex-direction définit la direction.
justify-content contrôle l'axe principal.
align-items contrôle l'axe secondaire.
gap ajoute des espaces.
flex-wrap permet le retour à la ligne.
flex-grow, flex-shrink et flex-basis contrôlent la taille des éléments.

Flexbox est l'un des outils principaux pour créer des interfaces modernes et responsives.
