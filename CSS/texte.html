✏️ Texte - CSS

CSS permet de contrôler l'apparence du texte sur une page web. Il est possible de modifier la taille, la couleur, l'alignement, la police et beaucoup d'autres propriétés.

Les propriétés de texte permettent d'améliorer la lisibilité et le design d'un site.

📌 Modifier la couleur du texte

La propriété color permet de changer la couleur d'un texte. 


p{

    color:

        white;

}

Il est possible d'utiliser plusieurs formats de couleurs : 


color:

red;



color:

#ff0000;



color:

rgb(255,0,0);

📌 Changer la taille du texte

La propriété font-size définit la taille du texte. 


h1{

    font-size:

        50px;

}

📌 Choisir une police

La propriété font-family permet de choisir la police utilisée. 


body{

    font-family:

        Arial;

}

Plusieurs polices peuvent être indiquées comme solution de secours. 


body{

    font-family:

        Arial, Helvetica, sans-serif;

}

📌 Utiliser des polices personnalisées

Il est possible d'importer des polices externes avec @font-face. 


@font-face{

    font-family:

        MyFont;


    src:

        url(font.ttf);

}



body{

    font-family:

        MyFont;

}

📌 Hauteur des lignes

La propriété line-height contrôle l'espace vertical entre les lignes.

}

Une valeur plus grande rend le texte plus agréable à lire.

📌 Largeur maximale du texte

La propriété max-width permet de limiter la largeur d'un bloc de texte. 


.article{

    max-width:

        700px;

}

Cela évite d'avoir des lignes trop longues difficiles à lire.

📌 Couper un texte trop long

Les propriétés suivantes permettent de gérer les textes qui dépassent.

        hidden;


    text-overflow:

        ellipsis;


    white-space:

Résultat : 


Ceci est un texte très lon...

📌 Retour à la ligne automatique


.text{

    overflow-wrap:

        break-word;

}

Permet de couper les mots trop longs pour éviter un dépassement.

📌 text-overflow

Permet de gérer un texte qui dépasse d'une zone.

        hidden;


    white-space:

        nowrap;


    text-overflow:

        ellipsis;

}

Voici un texte beaucoup trop...
ellipsis ajoute trois points (...) lorsque le texte est coupé.

⭐ Bonnes pratiques

✔ Utiliser line-height pour améliorer la lisibilité.

✔ Éviter les textes trop petits.

✔ Utiliser font-weight pour créer une hiérarchie visuelle.

✔ Utiliser text-align uniquement lorsque nécessaire.

✔ Éviter trop d'effets comme les ombres ou les décorations.

✔ Tester la lisibilité sur plusieurs écrans.
