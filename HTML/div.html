📦 Div - HTML

La balise <div> est l'une des balises les plus utilisées en HTML. Elle sert à créer des conteneurs permettant de regrouper plusieurs éléments ensemble.

Elle est principalement utilisée avec le CSS pour créer la mise en page d'un site web. 


<div>

    Contenu du conteneur

</div>
La balise <div> n'a aucun style particulier par défaut. Elle sert uniquement à organiser le contenu.

📌 Structure d'une div


<div>

    <h1>Titre</h1>

    <p>Description</p>

</div>

Une div peut contenir presque n'importe quel élément HTML : texte, images, boutons, autres div, formulaires, etc.

📌 Créer une div avec une classe


<div class="card">

    Mon contenu

</div>

L'attribut class permet de donner un nom à une div afin de pouvoir la cibler en CSS. 


.card{

    background:black;

    padding:20px;

}

Toutes les div possédant la classe card recevront ce style.

📌 Créer une div avec un id


<div id="menu">

    Navigation

</div>

L'attribut id permet d'identifier une div de manière unique. 


#menu{

    height:100px;

}
Une class peut être utilisée plusieurs fois.
Un id doit normalement être unique dans une page.

📌 Div imbriquées


<div class="container">


    <div class="header">

        En-tête

    </div>



    <div class="content">

        Contenu

    </div>


</div>

Une div peut contenir d'autres div. Cette technique est très utilisée pour organiser une page complexe.

📌 Modifier l'apparence d'une div avec CSS

Une div devient réellement utile lorsqu'elle est associée au CSS. On peut modifier sa taille, sa couleur, sa position ou encore son apparence. 


<div class="box">

    Ma boîte

</div>



.box{

    width:300px;

    height:150px;

    background:green;

}

Cette div aura une largeur de 300 pixels, une hauteur de 150 pixels et un fond vert.

📌 Modifier les dimensions


.box{

    width:500px;

    height:200px;

}

Les propriétés width et height permettent de définir la largeur et la hauteur d'une div. 


.box{

    max-width:900px;

}

max-width permet de limiter la taille maximale d'un élément.

📌 Ajouter de l'espace intérieur


.box{

    padding:20px;

}

La propriété padding ajoute un espace entre le contenu et les bords de la div. 


.box{

    padding:20px 40px;

}

Le premier nombre correspond au haut/bas et le second aux côtés gauche/droit.

📌 Ajouter un espace extérieur


.box{

    margin:30px;

}

La propriété margin ajoute un espace autour de la div. 


.box{

    margin:50px auto;

}

Cette méthode permet souvent de centrer une div horizontalement.

📌 Modifier le fond d'une div


.box{

    background:red;

}

La propriété background permet de changer la couleur de fond. 


.box{

    background:

    linear-gradient(
        red,
        blue
    );

}

Une div peut également utiliser des gradients.

📌 Ajouter des bordures


.box{

    border:

    2px solid black;

}

La propriété border ajoute une bordure autour de la div. 


.box{

    border-radius:20px;

}

border-radius permet d'arrondir les coins.

📌 Centrer une div


.container{

    width:800px;

    margin:auto;

}

Avec une largeur définie, margin:auto centre horizontalement une div.

Pour centrer correctement une div, elle doit généralement avoir une largeur définie ou un max-width.

📌 Utiliser Flexbox avec une div

Flexbox permet d'organiser facilement les éléments contenus dans une div. 


<div class="container">


    <div>Bloc 1</div>

    <div>Bloc 2</div>


</div>



.container{

    display:flex;

}

Les éléments enfants seront placés côte à côte.

📌 Aligner les éléments avec Flexbox


.container{

    display:flex;

    justify-content:center;

    align-items:center;

}

justify-content contrôle l'alignement horizontal.
align-items contrôle l'alignement vertical. 


.container{

    display:flex;

    gap:20px;

}

La propriété gap ajoute un espace entre les éléments.

📌 Direction des éléments


.container{

    display:flex;

    flex-direction:column;

}

Par défaut, Flexbox place les éléments en ligne. Avec column, ils sont placés verticalement.

📌 Créer une grille avec Grid


.container{

    display:grid;

    grid-template-columns:

    repeat(3,1fr);

}

CSS Grid permet de créer facilement des mises en page en colonnes. 


<div class="container">


    <div>Carte 1</div>

    <div>Carte 2</div>

    <div>Carte 3</div>


</div>

Les trois éléments seront répartis sur trois colonnes.

📌 Créer une carte avec une div

Les div sont souvent utilisées pour créer des cartes contenant plusieurs informations. 


<div class="card">


    <h2>Titre de la carte</h2>


    <p>

        Description de la carte.

    </p>


    <button>

        Voir plus

    </button>


</div>



.card{

    width:300px;

    padding:25px;

    border-radius:20px;

    background:#222;

}

Ce type de structure est utilisé pour créer :

✔ Des fiches produits.
✔ Des profils utilisateurs.
✔ Des articles.
✔ Des blocs d'informations.

📌 Créer une barre de navigation avec des div


<div class="navbar">


    <div class="logo">

        Mon Site

    </div>



    <div class="links">


        <a href="#">Accueil</a>

        <a href="#">Contact</a>


    </div>


</div>



.navbar{

    display:flex;

    justify-content:space-between;

    align-items:center;

}

Une div permet de séparer les différentes parties d'une navigation.

📌 Créer une structure de page


<div class="page">



    <div class="header">

        Header

    </div>



    <div class="main">

        Contenu

    </div>



    <div class="footer">

        Footer

    </div>



</div>

Avant l'arrivée des balises sémantiques comme <header> ou <footer>, les div étaient souvent utilisées pour construire toute une page.

Aujourd'hui, il est préférable d'utiliser les balises sémantiques lorsqu'elles existent. Les div restent utiles pour les groupes d'éléments qui n'ont pas de rôle précis.

📌 Cacher une div


.box{

    display:none;

}

La propriété display:none retire complètement la div de l'affichage. 


.box{

    visibility:hidden;

}

La propriété visibility:hidden cache la div mais conserve son espace.

📌 Modifier la position d'une div


.box{

    position:relative;

}

Une position relative permet de déplacer une div par rapport à sa position normale. 


.box{

    position:absolute;

    top:50px;

    left:100px;

}

Une position absolue place l'élément précisément dans son conteneur.

📌 Superposer des div


.container{

    position:relative;

}



.box{

    position:absolute;

    top:0;

    left:0;

}

Les positions absolues permettent de créer des éléments superposés.

Cette technique est souvent utilisée pour :

✔ Des menus déroulants.
✔ Des images avec du texte dessus.
✔ Des interfaces de jeu.

📌 Exemple complet avec plusieurs div


<div class="profile">


    <div class="image">

        Image

    </div>



    <div class="info">


        <h2>Yorin</h2>


        <p>

        Développeur web

        </p>


    </div>


</div>



.profile{

    display:flex;

    gap:20px;

    padding:20px;

}


.image{

    width:100px;

    height:100px;

}


.info{

    flex:1;

}

⭐ Bonnes pratiques

✔ Utiliser une div uniquement lorsqu'aucune balise plus précise n'existe.

✔ Donner des noms de classes compréhensibles.

✔ Éviter d'avoir trop de div inutiles.

✔ Utiliser Flexbox ou Grid pour organiser les éléments.

✔ Garder une structure HTML propre et bien indentée.

✔ Séparer la structure HTML du style CSS.

📌 Résumé

La balise <div> est un conteneur polyvalent permettant d'organiser une page HTML.

Elle est principalement utilisée avec le CSS pour créer des mises en page modernes grâce à Flexbox et Grid.
