🖼️ Images - HTML

Les images permettent d'ajouter des éléments visuels dans une page web. En HTML, elles sont affichées principalement avec la balise <img>. 


<img src="image.png">
La balise <img> est une balise seule. Elle ne possède pas de balise de fermeture.

📌 La structure d'une image


<img

src="photo.jpg"

alt="Une photo"

>

Une image possède généralement deux attributs importants :

src → indique l'emplacement de l'image.

alt → fournit une description de l'image.

📌 L'attribut src


<img src="chat.png">

L'attribut src indique au navigateur quelle image afficher. 


images/chat.png

Le chemin peut pointer vers un fichier situé dans un dossier du projet.

📌 Chemin relatif


<img src="images/logo.png">

Un chemin relatif indique l'emplacement de l'image depuis le fichier HTML actuel.

Les chemins relatifs sont recommandés pour les sites web car ils fonctionnent lorsqu'on déplace le projet complet.

📌 Chemin absolu


<img

src="https://site.com/image.png"

>

Un chemin absolu utilise une adresse complète vers une image en ligne.

Il faut éviter de dépendre d'images externes qui peuvent être supprimées ou modifiées.

📌 L'attribut alt


<img

src="chien.jpg"

alt="Un chien dans un parc"

>

L'attribut alt décrit l'image.

Il est utilisé lorsque :

✔ L'image ne charge pas.
✔ Une personne utilise un lecteur d'écran.
✔ Les moteurs de recherche analysent la page.

📌 Modifier la taille d'une image


<img

src="image.png"

width="300"

>

L'attribut width permet de définir la largeur de l'image en pixels. 


<img

src="image.png"

height="200"

>

L'attribut height permet de définir la hauteur de l'image.

Il est souvent préférable de modifier la taille des images avec le CSS plutôt qu'avec les attributs HTML.

📌 Modifier la taille avec CSS


img{

    width:300px;

}

Le CSS permet de contrôler plus facilement l'apparence des images. 


img{

    width:100%;

    height:auto;

}

Cette méthode conserve automatiquement les proportions de l'image.

📌 Rendre une image responsive


img{

    max-width:100%;

    height:auto;

}

Une image responsive s'adapte automatiquement à la taille de son conteneur.

La propriété max-width:100% empêche une image de dépasser de son élément parent.

📌 Ajouter une bordure à une image


img{

    border:

    3px solid green;

}

Les images peuvent utiliser les mêmes propriétés CSS que les autres éléments HTML. 


img{

    border-radius:20px;

}

border-radius permet d'arrondir les coins d'une image.

📌 Les formats d'images

Plusieurs formats d'images sont utilisés sur le web.

📌 JPEG / JPG


photo.jpg

Le format JPG est adapté aux photos.

Avantages :

✔ Taille réduite.
✔ Bonne qualité pour les photographies.

Inconvénient :

❌ Compression avec perte de qualité.

📌 PNG


logo.png

Le format PNG est souvent utilisé pour les logos et les images nécessitant de la transparence.

Avantages :

✔ Supporte la transparence.
✔ Bonne qualité.

Inconvénient :

❌ Fichiers souvent plus lourds.

📌 WebP


image.webp

Le format WebP est un format moderne optimisé pour le web.

Avantages :

✔ Bonne compression.
✔ Bonne qualité.
✔ Supporte la transparence.

📌 SVG


logo.svg

Le format SVG est utilisé pour les images vectorielles.

Il est particulièrement adapté pour :

✔ Les logos.
✔ Les icônes.
✔ Les illustrations simples.

Contrairement aux images classiques, un SVG peut être agrandi sans perdre de qualité.

📌 Choisir le bon format


Photo → JPG / WebP

Logo → SVG / PNG

Image avec transparence → PNG / WebP

Icône → SVG

📌 Mettre une image dans un lien


<a href="page.html">


    <img src="logo.png">


</a>

Une image peut être utilisée comme un bouton ou un lien.

📌 Ajouter un titre à une image


<img

src="chat.jpg"

title="Mon chat"

>

L'attribut title affiche une information lorsque la souris passe sur l'image.

📌 Organisation des images


MonSite

│

├── index.html

│

└── images

    ├── logo.png

    ├── photo.jpg

    └── icone.svg

Il est recommandé de placer les images dans un dossier séparé pour garder un projet organisé.

📌 La balise figure


<figure>


    <img

    src="photo.jpg"

    alt="Paysage"

    >


</figure>

La balise <figure> permet de regrouper une image avec son contenu associé.

📌 Ajouter une légende avec figcaption


<figure>


    <img

    src="montagne.jpg"

    alt="Une montagne"

    >



    <figcaption>

        Une montagne au coucher du soleil.

    </figcaption>


</figure>

La balise <figcaption> ajoute une légende à une image.

Cette structure est utile pour les articles, portfolios ou galeries d'images.

📌 Créer une galerie d'images


<div class="gallery">


    <img src="image1.jpg">


    <img src="image2.jpg">


    <img src="image3.jpg">


</div>



.gallery{

    display:grid;

    grid-template-columns:

    repeat(3,1fr);

    gap:20px;

}

Avec CSS Grid, il est facile de créer une galerie organisée.

📌 Ajouter une image de fond

Les images de fond sont généralement utilisées avec le CSS plutôt qu'avec HTML. 


<div class="banner">


    Bienvenue


</div>



.banner{

    background-image:

    url("background.jpg");


}

La propriété background-image permet d'ajouter une image en arrière-plan.

📌 Contrôler une image de fond


.banner{

    background-size:cover;

}

background-size:cover adapte l'image pour remplir entièrement le conteneur. 


.banner{

    background-position:center;

}

background-position permet de choisir la position de l'image.

📌 Ajouter une image avec une opacité


img{

    opacity:0.5;

}

La propriété opacity modifie la transparence d'une image. 


img:hover{

    opacity:1;

}

Cela permet par exemple de créer un effet au survol.

📌 Ajouter un effet au survol


img{

    transition:.3s;

}



img:hover{

    transform:scale(1.1);

}

L'image grandira légèrement lorsque la souris passe dessus.

📌 Exemple complet d'image


<figure>



    <img

    src="logo.png"

    alt="Logo du site"

    width="300"

    >



    <figcaption>

        Logo officiel du site.

    </figcaption>



</figure>

📌 Exemple d'image responsive complet


<img

src="photo.webp"

alt="Paysage"

class="responsive"

>



.responsive{

    max-width:100%;

    height:auto;

    border-radius:20px;

}

Cette méthode est souvent utilisée pour les images dans les sites modernes.

⭐ Bonnes pratiques

✔ Toujours ajouter un attribut alt aux images.

✔ Utiliser des formats adaptés comme WebP ou SVG.

✔ Éviter les images trop lourdes pour améliorer la vitesse du site.

✔ Utiliser le CSS pour gérer les tailles et les effets.

✔ Organiser les images dans un dossier dédié.

✔ Donner des noms de fichiers clairs :
   ✔ logo.png
   ✔ background-home.webp
   ❌ image1234.png

📌 Résumé

La balise <img> permet d'ajouter des images dans une page HTML.

Les attributs principaux sont :
src → emplacement de l'image.
alt → description.
width et height → dimensions.

Le CSS permet ensuite de créer des images modernes, responsives et adaptées à tous les écrans.
