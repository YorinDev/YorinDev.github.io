📊 Tableaux - HTML

Les tableaux HTML permettent d'organiser des données sous forme de lignes et de colonnes. Ils sont principalement utilisés pour afficher des informations structurées.

Un tableau HTML est composé de plusieurs éléments :

✔ <table> → crée le tableau.
✔ <tr> → crée une ligne.
✔ <td> → crée une cellule.
✔ <th> → crée une cellule d'en-tête.

📌 Créer un tableau simple


<table>


    <tr>


        <td>

            Java

        </td>



        <td>

            HTML

        </td>



    </tr>


</table>

La balise <table> contient l'ensemble du tableau.

Résultat : 


| Java | HTML |

Chaque balise <tr> représente une nouvelle ligne.

📌 La balise tr


<tr>


    Ligne du tableau


</tr>

La balise <tr> signifie Table Row. Elle permet de créer une ligne dans un tableau.

📌 La balise td


<td>


    Contenu de la cellule


</td>

La balise <td> signifie Table Data. Elle contient les données d'une cellule.

📌 La balise th


<th>


    Titre de colonne


</th>

La balise <th> crée une cellule d'en-tête.

Par défaut, son contenu est généralement :

✔ En gras.
✔ Centré.

📌 Ajouter des bordures avec CSS


table, td, th{

    border:1px solid white;

}

Par défaut, les tableaux HTML n'ont pas de bordures visibles. Le CSS permet d'en ajouter.

📌 Fusionner les bordures


table{

    border-collapse:

    collapse;

}

La propriété border-collapse fusionne les bordures des cellules.

Sans border-collapse:collapse, chaque cellule possède sa propre bordure.

📌 Modifier l'espacement des cellules


table{

    border-spacing:20px;

}

La propriété border-spacing ajoute un espace entre les cellules.

📌 Modifier la largeur d'un tableau


table{

    width:100%;

}

La propriété width permet de définir la taille du tableau. 


table{

    width:900px;

}

Le tableau aura une largeur fixe de 900 pixels.

📌 Styliser les cellules


td, th{

    padding:15px;

}

La propriété padding ajoute de l'espace à l'intérieur des cellules. 


th{

    background:#30ff70;

}

Il est possible de modifier l'apparence des en-têtes.

📌 Aligner le contenu


td{

    text-align:center;

}

La propriété text-align contrôle l'alignement horizontal du contenu. 


left

center

right

📌 Ajouter un effet au survol


tr:hover{

    background:#102010;

}

L'état :hover permet de modifier une ligne lorsque la souris passe dessus.

📌 Tableau avec alternance de couleurs


tr:nth-child(even){

    background:#101010;

}

nth-child() permet de cibler certains éléments selon leur position.

Les lignes paires peuvent avoir une couleur différente pour améliorer la lecture.

📌 Tableau responsive


.table-container{

    overflow-x:auto;

}

Un tableau large peut dépasser sur mobile. 


<div class="table-container">

    </table>



</div>

Le conteneur permet de faire défiler le tableau horizontalement.

📌 Quand utiliser un tableau ?


Utiliser un tableau pour :

✔ Prix

✔ Statistiques

✔ Classements

✔ Données organisées


Ne pas utiliser un tableau pour :

✘ Créer la mise en page d'un site

✘ Positionner des éléments

Les tableaux servent uniquement à afficher des données structurées.

📌 Tableau vs liste


Liste :

- Menu

- Étapes

- Éléments simples



Tableau :

| Nom | Score |

| Max | 100   |

Le choix dépend du type d'information à afficher.

⭐ Bonnes pratiques

✔ Toujours utiliser <th> pour les titres des colonnes.

✔ Utiliser <thead>, <tbody> et <tfoot> pour organiser le code.

✔ Ne pas utiliser les tableaux pour créer la structure d'un site.

✔ Ajouter du CSS pour améliorer la lisibilité.

✔ Prévoir une version responsive pour les petits écrans.

✔ Utiliser <caption> pour décrire le tableau.

📌 Résumé

Les tableaux HTML permettent d'afficher des données sous forme de lignes et de colonnes.

<table> → crée le tableau.
<tr> → crée une ligne.
<td> → crée une cellule.
<th> → crée un titre de colonne.

Avec CSS, les tableaux peuvent être personnalisés et adaptés aux écrans mobiles.
