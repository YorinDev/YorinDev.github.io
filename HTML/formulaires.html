📝 Formulaires HTML

Les formulaires HTML permettent de récupérer des informations venant des utilisateurs. Ils sont utilisés pour créer des pages de connexion, des recherches, des inscriptions ou des contacts. 


<form>

    Contenu du formulaire

</form>
La balise <form> crée simplement la structure du formulaire. Le traitement des données nécessite généralement un langage côté serveur comme PHP, Java ou JavaScript.

📌 Créer un formulaire simple


<form>


    <input type="text">


    <button>

        Envoyer

    </button>


</form>

Dans cet exemple :

<form> contient tous les éléments du formulaire.
<input> permet d'écrire une information.
<button> permet d'envoyer le formulaire.

📌 L'attribut action


<form action="traitement.php">

</form>

L'attribut action indique où envoyer les données du formulaire.

Si aucun action n'est indiqué, le formulaire est généralement envoyé vers la page actuelle.

📌 L'attribut method


<form method="post">

</form>

L'attribut method définit la manière d'envoyer les données. 


method="get"

method="post"

GET ajoute les données dans l'URL.
POST envoie les données dans la requête.

📌 La balise input


<input>

La balise <input> est utilisée pour créer des champs de saisie.

La balise <input> est une balise seule. Elle ne possède pas de fermeture.

📌 Champ texte


<input type="text">

Le type text permet de créer un champ pour écrire du texte. 


<input

type="text"

placeholder="Votre pseudo"

>

L'attribut placeholder affiche un texte indicatif dans le champ.

📌 Champ mot de passe


<input type="password">

Le type password permet de créer un champ où les caractères sont masqués. 


<input

type="password"

placeholder="Mot de passe"

>

📌 Champ email


<input type="email">

Le type email est utilisé pour récupérer une adresse mail. 


<input

type="email"

placeholder="exemple@email.com"

>
Le navigateur peut vérifier automatiquement si le format ressemble à une adresse email valide.

📌 Champ nombre


<input type="number">

Le type number permet d'entrer uniquement des nombres. 


<input

type="number"

min="0"

max="100"

>

Les attributs min et max définissent les limites autorisées.

📌 Champ date


<input type="date">

Le type date affiche un sélecteur de date. 


<input

type="date"

>

📌 Champ fichier


<input type="file">

Le type file permet à l'utilisateur d'envoyer un fichier. 


<input

type="file"

accept=".png,.jpg"

>

L'attribut accept limite les types de fichiers acceptés.

📌 Case à cocher


<input

type="checkbox"

>

Les cases à cocher permettent de sélectionner plusieurs choix. 


<label>

<input type="checkbox">

J'accepte les règles

</label>

📌 Boutons radio


<input

type="radio"

>

Les boutons radio permettent de choisir une seule option parmi plusieurs. 


<label>

<input

type="radio"

name="genre"

>

Homme

</label>



<label>

<input

type="radio"

name="genre"

>

Femme

</label>
Les boutons radio doivent partager le même attribut name pour fonctionner comme un groupe.

📌 Curseur (range)


<input type="range">

Le type range crée un curseur permettant de choisir une valeur. 


<input

type="range"

min="0"

max="100"

>

📌 La balise label


<label>

Nom :

<input type="text">

</label>

La balise <label> permet d'associer un texte à un champ. 


<label for="pseudo">

Pseudo

</label>


<input

id="pseudo"

type="text"

>

L'attribut for doit correspondre à l'id du champ.

📌 La balise textarea


<textarea>

Votre message

</textarea>

La balise <textarea> permet d'écrire un texte long. 


<textarea

placeholder="Votre commentaire"

>

</textarea>

📌 Modifier la taille d'un textarea


<textarea

rows="5"

cols="30"

>

</textarea>

rows définit le nombre de lignes.
cols définit la largeur.

📌 Liste déroulante


<select>


    <option>

        Java

    </option>


    <option>

        HTML

    </option>


</select>

La balise <select> crée une liste déroulante. 


<select>


    <option value="java">

        Java

    </option>



</select>

La balise <option> représente un choix disponible.

📌 Le bouton d'envoi


<button type="submit">

Envoyer

</button>

Le type submit permet d'envoyer les données du formulaire. 


<input type="submit" value="Envoyer">

Il est également possible d'utiliser un input comme bouton d'envoi.

📌 Bouton simple


<button type="button">

Cliquer

</button>

Un bouton avec type="button" ne fait rien par défaut. Il est souvent utilisé avec JavaScript.

📌 Bouton pour réinitialiser


<button type="reset">

Effacer

</button>

Le type reset remet tous les champs du formulaire à leur valeur initiale.

📌 L'attribut name


<input

type="text"

name="pseudo"

>

L'attribut name donne un nom à une donnée envoyée. 


pseudo=Yorin
Sans attribut name, la valeur d'un champ n'est généralement pas envoyée avec le formulaire.

📌 L'attribut value


<input

type="text"

value="Yorin"

>

L'attribut value définit une valeur par défaut.

📌 Champ obligatoire


<input

type="email"

required

>

L'attribut required oblige l'utilisateur à remplir le champ avant l'envoi.

📌 Champ désactivé


<input

type="text"

disabled

>

L'attribut disabled empêche l'utilisateur de modifier un champ.

📌 Champ en lecture seule


<input

type="text"

readonly

>

L'attribut readonly empêche la modification mais garde la possibilité d'envoyer la valeur.

📌 Ajouter une limite de caractères


<input

type="text"

maxlength="20"

>

L'attribut maxlength limite le nombre maximum de caractères.

📌 Vérification avec pattern


<input

type="text"

pattern="[A-Za-z]+"

>

L'attribut pattern permet d'utiliser une expression régulière pour vérifier une valeur.

Les expressions régulières permettent de définir un format précis pour une donnée.

📌 Exemple complet


<form>



<label for="pseudo">

Pseudo :

</label>



<input

id="pseudo"

name="pseudo"

type="text"

required

>




<br><br>




<label for="email">

Email :

</label>



<input

id="email"

name="email"

type="email"

required

>




<br><br>




<label for="message">

Message :

</label>



<textarea

id="message"

name="message"

>

</textarea>




<br><br>




<button type="submit">

Envoyer

</button>



</form>

Ce formulaire contient :

✔ Un champ pseudo.
✔ Un champ email.
✔ Une zone de message.
✔ Un bouton d'envoi.

📌 Envoyer vers une page


<form

action="traitement.php"

method="post"

>


</form>

Les informations seront envoyées vers traitement.php avec la méthode POST.

📌 Formulaire de connexion


<form>



<input

type="text"

placeholder="Pseudo"

>



<input

type="password"

placeholder="Mot de passe"

>



<button>

Connexion

</button>



</form>

⭐ Bonnes pratiques

✔ Toujours utiliser une balise <label> avec les champs.

✔ Ajouter required pour les informations importantes.

✔ Utiliser le bon type d'input selon la donnée demandée.

✔ Ajouter un attribut name aux champs envoyés.

✔ Ne jamais stocker de données sensibles uniquement en HTML.

✔ Vérifier les données côté serveur avant de les utiliser.

📌 Résumé

Les formulaires HTML permettent de récupérer des informations utilisateurs grâce à des balises comme <form>, <input>, <textarea>, <select> et <button>.

Ils sont la base des systèmes de connexion, d'inscription, de recherche et de contact sur les sites web.
