📋 Listes - HTML

Les listes permettent d'organiser plusieurs éléments de manière structurée. Elles sont utilisées pour créer des menus, afficher des informations ou présenter des données.

HTML possède principalement trois types de listes :

✔ Liste non ordonnée avec <ul>.
✔ Liste ordonnée avec <ol>.
✔ Liste de définitions avec <dl>.

📌 La balise li


<li>

Élément

</li>

La balise <li> représente un élément dans une liste.

La balise <li> doit normalement être utilisée à l'intérieur d'une balise de liste comme <ul> ou <ol>.

📌 Liste non ordonnée ul


<ul>


    <li>

        Java

    </li>



    <li>

        HTML

    </li>



    <li>

        CSS

    </li>


</ul>

La balise <ul> crée une liste avec des puces.

Résultat : 


• Java

• HTML

• CSS

📌 Liste ordonnée ol


<ol>


    <li>

        Installer un éditeur

    </li>



    <li>

        Créer un fichier HTML

    </li>



</ol>

La balise <ol> crée une liste numérotée.

Résultat : 


1. Installer un éditeur

2. Créer un fichier HTML

📌 Différence entre ul et ol


<ul>

Liste sans ordre

</ul>



<ol>

Liste avec un ordre

</ol>

Une liste ul est utilisée lorsque l'ordre n'a pas d'importance.

Une liste ol est utilisée lorsque les étapes doivent suivre un ordre précis.

📌 Liste imbriquée


<ul>


    <li>

            <li>

    </li>



</ul>

Une liste imbriquée est une liste placée à l'intérieur d'un élément d'une autre liste.

Résultat : 


• Langages

    • HTML

    • CSS

Il est possible de créer plusieurs niveaux de profondeur.

📌 Modifier le début d'une liste ol


<ol start="5">


    <li>

        Cinq

    </li>



    <li>

        Six

    </li>


</ol>

L'attribut start permet de choisir le nombre de départ d'une liste ordonnée.

Résultat : 


5. Cinq

6. Six

📌 Inverser une liste ordonnée


<ol reversed>


    <li>

        Trois

    </li>



    <li>

        Deux

    </li>



    <li>

        Un

    </li>



</ol>

L'attribut reversed inverse l'ordre des nombres.

📌 Modifier la valeur d'un élément


<ol>


    <li value="10">

        Dix

    </li>



    <li>

        Onze

    </li>



</ol>

L'attribut value permet de modifier le numéro d'un élément précis.

📌 Supprimer les puces avec CSS


ul{

    list-style-type:none;

}

La propriété list-style-type contrôle l'apparence des puces.

📌 Modifier le style des puces


ul{

    list-style-type:square;

}

Quelques valeurs possibles : 


disc

circle

square

none

Exemples :

disc → ●
circle → ○
square → ■

📌 Modifier le style des nombres


ol{

    list-style-type:

    upper-roman;

}

Les listes ordonnées peuvent utiliser différents styles. 


decimal

upper-roman

lower-roman

upper-alpha

lower-alpha

Exemples : 


1

I

A

a

📌 Position des puces


ul{

    list-style-position:

    inside;

}

La propriété list-style-position définit la position des puces. 


inside

outside

inside place les puces dans le contenu.
outside place les puces à l'extérieur.

📌 Les listes de définitions


<dl>


    <dt>

        HTML

    </dt>



    <dd>

        Langage utilisé pour créer des pages web.

    </dd>



</dl>

Les listes de définitions permettent de présenter un terme avec son explication.

Elles sont moins utilisées que <ul> et <ol>, mais elles sont utiles pour les glossaires ou les documentations.

📌 La balise dt


<dt>

Terme

</dt>

La balise <dt> représente le mot ou le terme à définir.

📌 La balise dd


<dd>

Description

</dd>

La balise <dd> contient la définition du terme.

📌 Créer un menu avec une liste

Les listes sont souvent utilisées pour créer les menus de navigation des sites web. 


<nav>


    <ul>


        <li>

            <a href="index.html">

                Accueil

            </a>

        </li>



        <li>

            <a href="contact.html">

                Contact

            </a>

        </li>



    </ul>


</nav>

Chaque élément du menu est un élément de liste contenant un lien.

📌 Transformer une liste en menu horizontal


ul{

    display:flex;

    gap:20px;

    list-style:none;

}

La propriété display:flex permet d'aligner les éléments horizontalement.

La combinaison <ul> + <li> + <a> est une méthode très utilisée pour créer des menus professionnels.

📌 Exemple de menu complet


<nav class="menu">


    <ul>


        <li>

            <a href="index.html">

                Accueil

            </a>

        </li>



        <li>

            <a href="HTML.html">

                HTML

            </a>

        </li>



        <li>

            <a href="CSS.html">

                CSS

            </a>

        </li>



    </ul>


</nav>

📌 Espacer les éléments d'une liste


li{

    margin-bottom:15px;

}

La propriété margin permet d'ajouter de l'espace entre les éléments.

<ul class="cards">

Les listes peuvent aussi servir à créer des interfaces modernes.

📌 Différence entre liste HTML et tableau


Liste :

Éléments simples

Navigation

Étapes



Tableau :

Données organisées

Lignes

Colonnes

Une liste sert à organiser des éléments.
Un tableau sert à afficher des données avec une structure en lignes et colonnes.

⭐ Bonnes pratiques

✔ Utiliser <ul> lorsque l'ordre des éléments n'a pas d'importance.

✔ Utiliser <ol> pour les étapes ou les classements.

✔ Toujours placer les éléments <li> dans une liste.

✔ Utiliser les listes pour les menus de navigation.

✔ Utiliser CSS pour modifier l'apparence des listes.

✔ Éviter d'utiliser des listes uniquement pour créer des espaces.

📌 Résumé

Les listes HTML permettent d'organiser des informations.

<ul> crée une liste avec des puces.
<ol> crée une liste numérotée.
<li> représente un élément.
<dl>, <dt> et <dd> servent aux définitions.

Avec CSS, les listes peuvent devenir des menus, des cartes ou des composants modernes.
