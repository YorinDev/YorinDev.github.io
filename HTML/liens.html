🔗 Liens - HTML

Les liens permettent de naviguer entre plusieurs pages, sites web ou fichiers. En HTML, ils sont créés principalement avec la balise <a>. 


<a href="https://google.com">

Google

</a>
La balise <a> signifie "anchor" (ancre). Elle permet de créer des liens cliquables.

📌 Structure d'un lien


<a href="page.html">

Voir la page

</a>

Un lien possède généralement :

<a> → la balise du lien.
href → la destination.
Le texte entre les balises → ce que l'utilisateur voit.

📌 L'attribut href


<a href="https://google.com">

Google

</a>

L'attribut href indique l'adresse vers laquelle le lien doit diriger. 


href="adresse"

La valeur peut être :

✔ Une autre page HTML.
✔ Un site externe.
✔ Un fichier.
✔ Une section de la page.

📌 Lien vers un site externe


<a href="https://www.youtube.com">

YouTube

</a>

Les liens externes utilisent généralement une adresse complète avec https://.

📌 Lien vers une autre page du site


<a href="contact.html">

Contact

</a>

Un chemin relatif permet de naviguer entre les pages d'un même projet.

📌 Lien vers un fichier dans un dossier


<a href="HTML/balises.html">

Voir les balises HTML

</a>

Un lien peut pointer vers un fichier situé dans un autre dossier. 


Projet

│

├── index.html

│

└── HTML

    └── balises.html

Depuis index.html, il faut indiquer le chemin vers le dossier.

📌 Remonter dans un dossier


<a href="../index.html">

Accueil

</a>

Les deux points .. permettent de revenir au dossier parent.

Dans tes fiches HTML, les liens utilisent par exemple ../css/style.css car les pages sont dans un sous-dossier.

📌 Lien vers une section de la page


<a href="#contact">

Contact

</a>

Un lien avec un # permet de déplacer l'utilisateur vers une partie précise de la page. 


<h2 id="contact">

Contact

</h2>

L'attribut id crée une destination pour l'ancre.

📌 Créer un bouton de navigation


<a href="page.html">

<button>

Cliquez

</button>

</a>

Il est possible de placer des éléments dans un lien.

Pour créer des boutons modernes, il est généralement préférable de styliser directement la balise <a> avec du CSS.

📌 Ouvrir un lien dans un nouvel onglet


<a

href="https://google.com"

target="_blank"

>

Google

</a>

L'attribut target="_blank" ouvre le lien dans un nouvel onglet.

📌 Sécuriser un nouvel onglet


<a

href="https://google.com"

target="_blank"

rel="noopener"

>

Google

</a>

L'attribut rel="noopener" améliore la sécurité lors de l'utilisation de nouveaux onglets.

📌 Lien vers une adresse email


<a href="mailto:test@email.com">

Envoyer un email

</a>

Le protocole mailto: ouvre automatiquement le logiciel de messagerie. 


mailto:adresse@email.com

📌 Ajouter un sujet à un email


<a

href="mailto:test@email.com?subject=Bonjour"

>

Contact

</a>

Il est possible de remplir automatiquement le sujet du mail.

📌 Lien vers un numéro de téléphone


<a href="tel:+33123456789">

Appeler

</a>

Le protocole tel: permet d'appeler un numéro depuis un appareil compatible.

📌 Télécharger un fichier


<a

href="document.pdf"

download

>

Télécharger

</a>

L'attribut download demande au navigateur de télécharger le fichier au lieu de l'afficher.

📌 L'attribut title


<a

href="page.html"

title="Voir la page"

>

Cliquez ici

</a>

L'attribut title affiche une information au survol de la souris.

📌 Lien avec une image


<a href="index.html">


    <img

    src="logo.png"

    alt="Logo"

    >


</a>

Une image peut devenir un élément cliquable en la plaçant dans une balise <a>.

📌 Créer une barre de navigation


<nav>


    <a href="index.html">

        Accueil

    </a>



    <a href="contact.html">

        Contact

    </a>



</nav>

La balise <nav> est utilisée pour regrouper les liens de navigation principaux d'un site.

📌 Exemple de menu horizontal


<nav class="menu">


    <a href="index.html">

        Accueil

    </a>



    <a href="HTML.html">

        HTML

    </a>



    <a href="CSS.html">

        CSS

    </a>



</nav>



.menu{

    display:flex;

    gap:20px;

}

Avec CSS Flexbox, les liens peuvent être affichés côte à côte.

📌 Modifier l'apparence des liens


a{

    color:green;

    text-decoration:none;

}

La propriété text-decoration permet de supprimer le soulignement par défaut.

📌 L'état hover


a:hover{

    color:

    lime;

}

:hover s'applique lorsque la souris passe au-dessus du lien.

📌 L'état visited


a:visited{

    color:purple;

}

:visited permet de modifier l'apparence d'un lien déjà visité.

📌 L'état active


a:active{

    color:red;

}

:active s'applique pendant le clic sur le lien.

📌 Ajouter une animation aux liens


a{

    transition:.3s;

}



a:hover{

    transform:

    translateY(-5px);

}

Les transitions permettent de créer des effets plus fluides.

📌 Créer un lien stylisé comme un bouton


<a class="button"

href="page.html">


    Commencer


</a>



.button{

    padding:15px 30px;

    background:green;

    color:white;

    border-radius:10px;

    text-decoration:none;

}

Un lien peut être transformé en bouton uniquement avec du CSS.

Site

├── index.html

├── contact.html

└── CSS.html



<a href="HTML.html">

Chaque page peut être reliée avec des liens relatifs.

📌 Navigation vers une section d'une autre page


<a href="page.html#partie1">

Voir la partie 1

</a>

Il est possible de cibler une section précise d'une autre page. 


<h2 id="partie1">

Partie 1

</h2>

📌 Exemple complet


<nav>


    <a href="index.html">

        Accueil

    </a>



    <a href="cours.html">

        Cours

    </a>



    <a href="contact.html">

        Contact

    </a>



</nav>

Ce menu permet de naviguer facilement entre les différentes pages d'un site.

⭐ Bonnes pratiques

✔ Utiliser des chemins relatifs pour les pages du même site.

✔ Utiliser https:// pour les liens externes.

✔ Ajouter un texte clair qui explique la destination du lien.

✔ Éviter les textes comme "Cliquez ici" sans contexte.

✔ Ajouter rel="noopener" avec target="_blank".

✔ Vérifier régulièrement que les liens fonctionnent.

✔ Utiliser <nav> pour les menus principaux.

📌 Résumé

Les liens HTML utilisent principalement la balise <a>.

L'attribut essentiel est href, qui définit la destination du lien.

Les liens permettent de créer la navigation d'un site, d'ouvrir des pages externes, de télécharger des fichiers ou de contacter quelqu'un.
