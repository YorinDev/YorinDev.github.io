🌐 Balises HTML

Les balises HTML permettent de structurer une page web. Elles indiquent au navigateur comment afficher les différents éléments : texte, images, liens, listes, formulaires, etc. 


<balise>

Contenu

</balise>
La majorité des balises HTML possèdent une balise d'ouverture et une balise de fermeture. Certaines balises sont cependant seules, comme <img> ou <br>.

📌 Structure d'une balise


<p>Bonjour !</p>

Dans cet exemple :

<p> → ouverture de la balise.
Bonjour ! → contenu.
</p> → fermeture de la balise.

📌 Les titres


<h1>Titre principal</h1>

<h2>Sous-titre</h2>

<h3>Titre niveau 3</h3>

Les balises <h1> à <h6> permettent de créer des titres.

Il est recommandé d'utiliser un seul <h1> par page pour représenter le titre principal.

📌 Les paragraphes


<p>
Ceci est un paragraphe.
</p>

La balise <p> sert à afficher un bloc de texte.

📌 Retour à la ligne


Bonjour<br>
Comment ça va ?

La balise <br> force un retour à la ligne.

📌 Mettre du texte en valeur


<b>Texte en gras</b>

<i>Texte en italique</i>

<u>Texte souligné</u>

Ces balises permettent de modifier l'apparence du texte. 


<strong>Texte important</strong>

<em>Texte accentué</em>
<strong> et <em> sont préférées car elles donnent aussi une information sur l'importance du texte pour les moteurs de recherche et l'accessibilité.

📌 Créer un lien


<a href="https://google.com">

Google

</a>

La balise <a> permet de créer un lien vers une autre page ou un autre site. 


<a href="page.html">

Voir la page

</a>

Le paramètre href indique la destination du lien.

📌 Ouvrir un lien dans un nouvel onglet


<a 
href="https://google.com"
target="_blank">

Google

</a>

L'attribut target="_blank" ouvre le lien dans un nouvel onglet.

📌 Ajouter une image


<img 
src="image.png"
alt="Description">

La balise <img> permet d'afficher une image.

La balise <img> n'a pas de fermeture car elle contient directement toutes ses informations dans ses attributs. 

<img
src="chat.jpg"
alt="Un chat"
width="300">

📌 Les listes

HTML possède plusieurs types de listes.

📌 Liste non ordonnée


<ul>

    <li>Java</li>

    <li>HTML</li>

    <li>CSS</li>

</ul>

La balise <ul> crée une liste avec des points.
Chaque élément utilise la balise <li>.

📌 Liste ordonnée


<ol>

    <li>Créer un fichier HTML</li>

    <li>Ajouter du contenu</li>

    <li>Ajouter du CSS</li>

</ol>

La balise <ol> crée une liste numérotée.

📌 Les tableaux


<table>

    <tr>

        <th>Nom</th>

        <th>Âge</th>

    </tr>


    <tr>

        <td>Alex</td>

        <td>15</td>

    </tr>

</table>

Les tableaux permettent d'organiser des données sous forme de lignes et colonnes.

<tr> représente une ligne.
<th> représente une cellule de titre.
<td> représente une cellule normale.

📌 Les formulaires


<form>

    <input type="text">

    <button>

        Envoyer

    </button>

</form>

La balise <form> permet de créer une zone où l'utilisateur peut entrer des informations.

📌 Champs de formulaire


<input type="text">

<input type="password">

<input type="email">

<input type="number">

La balise <input> crée différents types de champs.

📌 Bouton


<button>

Envoyer

</button>

La balise <button> crée un bouton cliquable.

📌 Zone de texte


<textarea>

Votre message

</textarea>

La balise <textarea> permet d'écrire un texte plus long.

📌 La balise div


<div>

    Contenu de la section

</div>

La balise <div> sert à créer un conteneur. Elle permet de regrouper plusieurs éléments HTML afin de les organiser avec du CSS ou du JavaScript. 


<div class="card">

    <h2>Titre</h2>

    <p>Description</p>

</div>

📌 Les balises sémantiques

Les balises sémantiques indiquent le rôle d'une partie de la page. Elles rendent le code plus clair et améliorent l'accessibilité.

📌 Header


<header>

    Logo et navigation

</header>

La balise <header> représente l'en-tête d'une page ou d'une section.

📌 Navigation


<nav>

    <a href="#">Accueil</a>

</nav>

La balise <nav> contient les liens de navigation principaux.

📌 Main


<main>

    Contenu principal

</main>

La balise <main> contient le contenu principal de la page.

📌 Section


<section>

    Une partie du contenu

</section>

La balise <section> permet de séparer une page en différentes parties.

📌 Article


<article>

    Article de blog

</article>

La balise <article> représente un contenu indépendant comme un article, une publication ou une fiche.

📌 Footer


<footer>

    Informations du site

</footer>

La balise <footer> représente le pied de page.

📌 Ajouter un commentaire


<!-- Ceci est un commentaire -->

Les commentaires permettent d'ajouter des notes dans le code qui ne seront pas affichées sur la page.

📌 Les attributs


<a href="page.html">

Lien

</a>

Les attributs ajoutent des informations supplémentaires aux balises.

Un attribut se place toujours dans la balise d'ouverture. 

<img 
src="image.png"
alt="Description">

Dans cet exemple :

src indique l'emplacement de l'image.
alt donne une description de l'image.

📌 L'attribut class


<p class="important">

Texte

</p>

L'attribut class permet d'appliquer un style CSS à plusieurs éléments.

📌 L'attribut id


<div id="menu">

Menu

</div>

L'attribut id donne un identifiant unique à un élément.

Contrairement à une class, un id ne doit être utilisé qu'une seule fois dans une page.

📌 Exemple complet


<!DOCTYPE html>

<html>


<head>

    <title>Mon site</title>

</head>



<body>


<header>

    Mon site

</header>



<main>


    <h1>Bienvenue</h1>


    <p>

        Ceci est ma première page.

    </p>



</main>



<footer>

    Copyright 2026

</footer>


</body>


</html>

⭐ Bonnes pratiques

✔ Utiliser des balises adaptées au contenu.

✔ Toujours fermer les balises qui nécessitent une fermeture.

✔ Utiliser des balises sémantiques comme <header>, <main> et <footer>.

✔ Ajouter un attribut alt aux images.

✔ Garder un code propre et bien indenté.

✔ Éviter d'utiliser uniquement des <div> quand une balise plus précise existe.
