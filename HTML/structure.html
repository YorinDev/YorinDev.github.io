🏗️ Structure - HTML

Une page HTML est composée d'une structure précise permettant au navigateur de comprendre son contenu. Chaque partie possède un rôle spécifique. 


<!DOCTYPE html>

<html>


    <head>


    </head>



    <body>


    </body>


</html>
Une page HTML contient toujours deux grandes parties :

<head> → informations sur la page.
<body> → contenu visible par l'utilisateur.

📌 Le DOCTYPE


<!DOCTYPE html>

Le DOCTYPE indique au navigateur que le document utilise la version moderne HTML5.

Le DOCTYPE n'est pas une balise HTML. Il sert uniquement à déclarer le type du document.

📌 La balise html


<html>


    Contenu de la page


</html>

La balise <html> contient toute la page HTML. 


<html lang="fr">

L'attribut lang indique la langue principale du document.

L'attribut lang="fr" aide les moteurs de recherche et les outils d'accessibilité.

📌 La partie head


<head>


    Informations de la page


</head>

La partie <head> contient les informations qui ne sont pas directement visibles dans la page.

Elle contient généralement :

✔ Le titre.
✔ L'encodage.
✔ Les fichiers CSS.
✔ Les scripts JavaScript.
✔ Les métadonnées.

📌 L'encodage UTF-8


<meta charset="UTF-8">

La balise <meta charset="UTF-8"> définit l'encodage utilisé par la page.

UTF-8 permet d'afficher correctement la majorité des caractères :

✔ Accents (é, è, à).
✔ Symboles.
✔ Caractères de nombreuses langues.

📌 La balise viewport


<meta

name="viewport"

content="width=device-width, initial-scale=1.0"

>

Cette balise permet d'adapter l'affichage du site aux appareils mobiles.

La balise viewport est essentielle pour créer des sites responsives.

📌 Le titre de la page


<title>

Mon site

</title>

La balise <title> définit le titre affiché dans l'onglet du navigateur. 


<title>

Forum Java FR

</title>

📌 Ajouter un fichier CSS


<link

rel="stylesheet"

href="style.css"

>

La balise <link> permet de connecter un fichier CSS à la page HTML.

Exemple d'organisation : 


Projet

│

├── index.html

│

└── css

    └── style.css



<link

rel="stylesheet"

href="css/style.css"

>

📌 Ajouter un fichier JavaScript


<script

src="script.js"

>

</script>

La balise <script> permet d'ajouter du JavaScript à une page.

Le JavaScript est souvent placé juste avant la fermeture de </body> pour améliorer le chargement de la page.

📌 La partie body


<body>


    Contenu visible


</body>

La balise <body> contient tout ce que l'utilisateur voit :

✔ Texte.
✔ Images.
✔ Boutons.
✔ Liens.
✔ Sections.
✔ Formulaires.

📌 Structure simple d'une page


<body>


    <h1>

        Titre

    </h1>



    <p>

        Texte

    </p>



    <img

    src="image.png"

    >



</body>

Le contenu visible est placé dans le body.

📌 La balise header


<header>


    En-tête du site


</header>

La balise <header> représente l'en-tête d'une page ou d'une section.

Elle contient souvent :

✔ Un logo.
✔ Un titre.
✔ Un menu.

📌 La balise nav


<nav>


    Liens de navigation


</nav>

La balise <nav> contient les liens permettant de naviguer dans le site. 


<nav>


    <a href="index.html">

        Accueil

    </a>



</nav>

📌 La balise main


<main>


    Contenu principal


</main>

La balise <main> contient la partie principale de la page.

Une page doit généralement avoir un seul élément <main>.

📌 La balise section


<section>


    Une partie du contenu


</section>

La balise <section> permet de regrouper une partie du contenu ayant un même sujet.

Exemple : 


<section>


    <h2>

        Mes projets

    </h2>



    <p>

        Présentation de mes projets.

    </p>



</section>

📌 La balise article


<article>


    Contenu indépendant


</article>

La balise <article> représente un contenu pouvant être compris seul.

Exemples d'utilisation :

✔ Article de blog.
✔ Actualité.
✔ Publication.
✔ Message de forum.

📌 La balise aside


<aside>


    Informations secondaires


</aside>

La balise <aside> contient du contenu complémentaire.

Exemples :

✔ Barre latérale.
✔ Liens associés.
✔ Informations supplémentaires.

📌 La balise footer


<footer>


    Pied de page


</footer>

La balise <footer> représente le bas d'une page ou d'une section.

Elle contient souvent :

✔ Copyright.
✔ Informations de contact.
✔ Liens secondaires.

📌 Structure complète d'une page HTML


<!DOCTYPE html>


<html lang="fr">



<head>


    <meta charset="UTF-8">


    <meta

    name="viewport"

    content="width=device-width, initial-scale=1.0">



    <title>

        Mon site

    </title>



    <link

    rel="stylesheet"

    href="style.css">



</head>





<body>



    <header>


        Logo + titre


    </header>




    <nav>


        Menu


    </nav>




    <main>



        <section>


            Contenu


        </section>



        <article>


            Article


        </article>



    </main>




    <footer>


        Copyright


    </footer>



</body>



</html>

📌 Structure d'un projet web


MonSite


│

├── index.html


│

├── css


│   └── style.css


│

├── js


│   └── script.js


│

└── images


    └── logo.png

Séparer les fichiers permet de garder un projet organisé.

📌 Les balises sémantiques


header

nav

main

section

article

aside

footer

Ces balises donnent du sens à la structure de la page.

Les balises sémantiques améliorent l'accessibilité et permettent aux moteurs de recherche de mieux comprendre le contenu.

📌 Balises div et span


<div>


    Bloc de contenu


</div>



<span>


    Petit élément


</span>

<div> sert à créer des conteneurs généraux.

<span> sert à modifier une petite partie d'un texte.

📌 Comment organiser une page


Page


│

├── Header

│

├── Navigation

│

├── Contenu principal

│

│   ├── Sections

│   └── Articles

│

└── Footer

Une bonne organisation rend le code plus facile à lire et à modifier.

⭐ Bonnes pratiques

✔ Toujours commencer par <!DOCTYPE html>.

✔ Ajouter l'attribut lang dans la balise <html>.

✔ Utiliser UTF-8 pour éviter les problèmes de caractères.

✔ Séparer HTML, CSS et JavaScript dans des fichiers différents.

✔ Utiliser les balises sémantiques quand elles ont un sens.

✔ Garder une structure claire et bien indentée.

✔ Éviter de mettre tout le contenu dans des <div>.

📌 Résumé

Une page HTML possède une structure principale composée de :

<html> → contient toute la page.
<head> → informations invisibles.
<body> → contenu visible.

Les balises comme <header>, <main>, <section> et <footer> permettent d'organiser proprement un site.
